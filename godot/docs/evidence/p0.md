## 已知限制

- 只有标题、主页、工作台静态视觉；按钮除导航外只显示 P0 提示，不执行订单、存档、商店、日历、结局或新手引导。
- 主页 HUD 和工作台示例配方是演示数据，不代表正式业务状态。
- 工作台拖拽为表现层演示：有预览、落锅高亮、落锅/取消提示，但不消耗词条或原料；正式事务在 P2。
- Windows 截图来自开发机；安卓画面、触控、字体观感、飞行模式首次启动、后台恢复和性能未验证。
- APK 使用调试签名；正式包名、签名、图标与商店素材在 P6 冻结。
- `boot.gd` 的 `--p0-screen` 与 `p0_capture.gd` 的 `--p0-capture` 是 P0 证据钩子，正式发布前移除或显式关闭。
