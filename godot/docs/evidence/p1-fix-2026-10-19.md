| S01 | 从旧侧恢复后，下次保存可能破坏唯一可用备份 | `commit()` 按最高 marker 选择写入侧，而不是按实际通过验证的有效侧 | 新增双侧独立检查；提交写“有效提交的对侧”；generation 取所有 marker/有效代最大值 +1；任一 unsupported 侧禁止覆盖 | `test_save_faults.gd` S01：回退 A 后写 B；A 字节不变；B 短写失败仍能恢复 A |

| S03 | 一侧 marker 短写导致完整另一侧无法恢复 | `_current_marker()` 任一侧解析失败就提前返回 | A/B 独立检查；截断 marker 视为该侧无有效提交，另一侧有效则加载并记录 `ignored`；marker 读失败视为不可判定并锁定 | S03：B marker 截断/缺失仍加载 A；B marker 读失败返回 `SAVE_READ_FAILED` |

| F01 | 内容负例门禁未闭环，部分非法类型被导出/加载放过 | Python `or {}`/`or []` 吞掉空容器类型；GDScript 只查顶层结构 | 导出器改为显式 dict/list 类型检查；新增 `ContentValidation` 逐集合校验引用、枚举、数组/对象类型；新增 Python 与 GDScript 负例 | 5 个 Python 负例 + 5 个 GDScript 负例，全部失败并定位字段 |
