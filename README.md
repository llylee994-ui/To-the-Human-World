# 《寄往人间》 To the Human World

叙事经营 + 轻推理 + 配方组合 + 多结局游戏。

玩家经营一间位于“人间之外”海岸边的魔药铺：打捞漂流瓶、阅读来信、从信中裁剪词条、炼制魔药、
按“字面要求”完成订单并寄回人间。人间人物不知道魔药铺，念头自行汇聚成信；在满足陌生人愿望的过程中，信件、地址与人物后续会逐渐拼出
一桩谋杀案的真相，以及玩家自己的身份。

> TapTap 游戏比赛主题：**涌现**
>
> 核心句：**魔药从不理解愿望，它只理解文字。**
