使用标题为“寄往人间”的 Maker 本地窗口。应完整显示横屏主页、顶部真实金币和“第 N 天”，右上“结束当天”；正常入口没有热区轮廓或调试 ID。

## 建议按这个顺序体验一封信

1. **点捞网 → 点“开始捕捞”**：只有这一步才执行捕捞命令；成功后显示实际收到的信，并消耗对应次数。若业务不允许，显示原因，不假装收到了信。
2. **查看信件并向下滚动**：应能看到真实标题、寄信人、自我介绍、正文、寄信地址、委托要求、报酬。要求与报酬是正式数据，不是背景上的装饰笔迹。
3. **点一个“剪下……”按钮**：对应正文位置留下空白，按钮变成“已剪”；滚动位置保持；再次点击不能再得到一份词卡。
4. **关闭 → 返回主页 → 点信纸**：仍打开对应信件，已剪结果保留。**点托盘**，能看到这张词卡的类别和来源。
5. **回到信件 → 点“接下这份委托”**：此时才接单，进入炼药功能工作区。已经接单的信显示查看委托；已完成的信可查看对应记录。
6. **选词卡／原料投入 → 返回主页 → 再点炉子**：投料仍在。取出主词时，不应悄悄把辅词换成主词。同名不同来源词卡保持各自身份。
7. **显式试做并产生结果 → 关闭 → 返回主页**：顶部应能重新打开“待处理结果”；结果未因返回而丢失。读记录书不能把它自动发货。
8. **按意愿确认发货或重置**：只有对应显式按钮执行；失败时保留实际状态并显示原因。重置过的试做记录仍应能从记录书查看。

## 购买与结束当天

- 商店：记下金币和某原料数量，买一份后核对扣款、库存增加、今日余量减少；余额不足或限购耗尽时不能购买。关闭回到进入商店之前的场景。
- 结束当天：点击顶部按钮先出现确认层，取消不变天；满足条件并确认后天数才 +1。草稿非空或有待处理结果时，显示业务限制，不自动清空投料来跨天。
- 购买、剪词、跨天保存失败：面板内显示失败提示，金币／词卡／天数不能假报成功。自动故障注入已经在隔离存档运行，人工验收无需破坏真实存档模拟故障。
