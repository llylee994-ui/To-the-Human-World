## 开始检查

使用标题为“寄往人间”的 Maker 本地窗口。应完整显示横屏主页、顶部真实金币和“第 N 天”，右上“结束当天”；正常入口没有热区轮廓或调试 ID。

先测试下面的导航，再测试购买、剪词、接单与跨天。后面这些操作会按现有业务真实保存，不是展示按钮。关闭窗口或官方刷新后的存档恢复要另行记录，不能用后台测试代替。

## 逐个点击物件

| 点击什么 | 应出现什么 | 关闭／返回后的预期 |
|---|---|---|
| 海面船的船体或船帆 | “商队商店”，真实金币、原料名称、已有数量、今日余量、单价及购买按钮 | 回进入前场景；仅点船不扣钱 |
| 左边捞网的网兜／杆主体 | 标明“功能界面”的海边捕捞页，显示当天剩余次数和实际可捕捞状态 | 返回主页；仅点捞网不收信、不扣次数 |
| 桌上词条托盘主体 | 左侧“词条栏”，有分类、词卡来源、可用／已消耗／已投入状态；没词卡时说明如何获得 | 侧栏只挡左侧，关闭后主页仍可操作 |
| 桌上信纸 | 优先打开刚选中或当前委托所属信件；尚未选定时打开真实来信列表；没有来信时显示“还没有收到信件” | 不自动接单、发货或重置；重开保留已剪状态 |
| 炼药炉主体 | 明确标记为功能界面的炼药工作区；有订单时显示委托与已保存投料，无订单时给出引导 | 返回主页再打开，投料仍在；仅打开不熬制、不发货 |
| 右下黄色档案袋 | 案件板。当前业务未开放时明确显示尚未开放 | 关闭回原场景；没有虚构人物或线索 |
| 右下记录书 | 右侧故事记录页，只列已收到的故事；可查看保存的试做记录，包括已重置记录 | 查看历史不重新计算、不发货、不结算 |
| 桌前抽屉把手（任一把手） | “来信抽屉”真实已收信件列表 | 选择来信后进入同一阅读组件；“返回”回列表，再“关闭”回主页 |

## 建议按这个顺序体验一封信

1. **点捞网 → 点“开始捕捞”**：只有这一步才执行捕捞命令；成功后显示实际收到的信，并消耗对应次数。若业务不允许，显示原因，不假装收到了信。
2. **查看信件并向下滚动**：应能看到真实标题、寄信人、自我介绍、正文、寄信地址、委托要求、报酬。要求与报酬是正式数据，不是背景上的装饰笔迹。
3. **点一个“剪下……”按钮**：对应正文位置留下空白，按钮变成“已剪”；滚动位置保持；再次点击不能再得到一份词卡。
4. **关闭 → 返回主页 → 点信纸**：仍打开对应信件，已剪结果保留。**点托盘**，能看到这张词卡的类别和来源。
5. **回到信件 → 点“接下这份委托”**：此时才接单，进入炼药功能工作区。已经接单的信显示查看委托；已完成的信可查看对应记录。
6. **选词卡／原料投入 → 返回主页 → 再点炉子**：投料仍在。取出主词时，不应悄悄把辅词换成主词。同名不同来源词卡保持各自身份。
7. **显式试做并产生结果 → 关闭 → 返回主页**：顶部应能重新打开“待处理结果”；结果未因返回而丢失。读记录书不能把它自动发货。
8. **按意愿确认发货或重置**：只有对应显式按钮执行；失败时保留实际状态并显示原因。重置过的试做记录仍应能从记录书查看。

## 购买与结束当天

- 商店：记下金币和某原料数量，买一份后核对扣款、库存增加、今日余量减少；余额不足或限购耗尽时不能购买。关闭回到进入商店之前的场景。
- 结束当天：点击顶部按钮先出现确认层，取消不变天；满足条件并确认后天数才 +1。草稿非空或有待处理结果时，显示业务限制，不自动清空投料来跨天。
- 购买、剪词、跨天保存失败：面板内显示失败提示，金币／词卡／天数不能假报成功。自动故障注入已经在隔离存档运行，人工验收无需破坏真实存档模拟故障。

## 点击范围与屏幕比例

1. 分别点船边水波、图片透明边、桌面空白、瓶子装饰，应不误开相邻面板。捞网网眼内部应能点击。
2. 弹窗打开时点它外面的炉子／信纸，不能穿透触发；关闭弹窗的那一下不能再触发下方物件。
3. 左／右侧栏只阻挡自己的范围；其外可见物件仍能点击。
4. 调整窗口为 16:9、19.5:9、20:9、4:3：全部功能物件保留，图像不拉伸，热区跟随主体；关闭／返回按钮始终能点到。
5. 手机实际检查横屏、刘海、Tap 胶囊、圆角、拇指点击、长文滑动。桌面改变窗口比例不等于手机通过。
