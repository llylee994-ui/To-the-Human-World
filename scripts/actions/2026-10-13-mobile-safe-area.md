# 手机横屏安全区修正

问题证据：用户提供首页、海边、商店三张 2048×917 手机截屏。左侧出现外层海面与内层场景接缝，右上角胶囊遮挡结束当天和关闭按钮。

改动：游戏画布按父容器绝对偏移延伸到 UI 全视口，背景不再跟着 SafeAreaView 收缩；HUD、海边底栏、商店正文与其他弹窗分别避开刘海和底部安全区。通过正常 `sdk` 全局绑定获取胶囊，避免 `rawget` 绕过引擎全局属性；移动端桥尚未提供矩形时保留 144 基准像素宽、80 高的右上区域，后续以真实矩形更新。窄屏顶部操作移至胶囊下方；视口/安全区改变会更新当前打开的商店。样式仅在变更时写入。

验证（剧情配置使用本次修正前的已提交 `aff584d`，保留其他未提交文案和数值）：MobileSafeArea 15、HomePresentation 33、HomeHud 50、ShopView 51、TravelTicket 46、SeasideFlow 89、HomeZoom 383、HomeEntry 303，共 970 项。最初新增回归在旧实现上因绑定 SDK 未避让失败，修正后通过；包含打开商店时安全区变换，不写游戏存档。

离线证据：`docs/验证/evidence/mobile-safe-r1/`，2048×917、1280×720、800×360、1024×768 各有首页/海边/商店截图；实际 Lua 控件属性经 CSS 重放，字体按点换算、加入模拟胶囊/刘海。12 个投影的操作按钮均在视口内且与模拟胶囊不重叠。图片标注 OFFLINE，不作为手机、Yoga、NanoVG或触摸验收。

本地窗口状态：stopped / process_alive=false，未重新启动。Lua LSP 使用本轮持续监视诊断确认无错误，现有警告单独保留。独立审查未发现阻塞问题。Maker 手机预览更新后，需手机退出旧测试并重新扫码确认背景接缝、胶囊区域和横屏旋转；构建成功不等同于真机验收。
