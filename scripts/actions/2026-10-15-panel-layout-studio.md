# 托盘与记录书素材排版室

用户要求自己摆放两个界面的素材，供前端接入参考。本轮不使用子代理。复用 scripts/layout-editor 的持久化、图层、拖动/缩放/旋转、撤销、预览和 ZIP 导出。

设计：独立本地项目与启动入口，两个 520×1040 的面板近景，提前载入原始 PNG；不覆盖其它排版项目，不直接改游戏运行布局。页面和图层保留稳定 ID，素材附项目相对路径与 SHA-256，后续按导出坐标人工对照接入。

实施顺序：先验证初始化、素材原字节、重复启动保留用户改动与完整导出；再增加独立启动器与幂等初始化；运行既有存储/HTTP检查并在真实浏览器验证移动、保存、切页和导出。

已完成：panel_materials.py、根目录专用启动 .cmd、server 的可选初始化钩子，以及现有编辑器项目名显示。数据只保存在 scripts/layout-editor/.local/panel-materials；首次从完整 ZIP 事务导入预置，重复启动或已有内容时不再初始化。来源原图不改像素，sourceAssets 和 SHA-256 保留在导出项目。

验证：16 项 Python 存储与 HTTP 检查通过；独立数据目录的真实 Chromium 检查通过两个页面、10 图、指针拖动、撤销、切页、键盘微调、刷新保留、项目导出和无手柄预览。首轮浏览器检查因切页请求尚未完成便断言而失败，改为等待当前页面名称后通过，未修改用户项目。截图已查看，位于 scripts/layout-editor/.local/panel-browser-1792036273747。

实际服务 PID 3192，http://127.0.0.1:18767。正式设计项目仍 revision 0；浏览器操作测试只在隔离项目进行。Codex 浏览器已显示可编辑窗口，重复的只读标签已关闭。没有提交、推送或修改游戏布局；之前记录书接入成果原样保留。
