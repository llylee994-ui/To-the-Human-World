## 7. 2026-10-04 运行环境专项核对与续验

**当前结论：当前工程不符合 Maker 0.0.36 官方直接读取工程条件；持久环境尚未确定，V13 继续阻塞。**

- 当前 CLI 没有保留存档或强制直读参数。原生 File 的项目/用户隔离说明不保证预览缓存生命周期；未启动不受支持的手工 Runtime 入口，未改配置、玩法或云存档。
- 已创建[Maker 官方 Issue #568](https://github.com/taptap/instant-games-open-mcp/issues/568)，询问支持的持久目录、跨会话身份、版本/命令，以及需要时正式原生客户端/测试包的交付方式。仅发布通用现象和问题；详细过程见[行动记录](actions/2026-10-03-b6-acceptance-and-text-contract.md)。目前没有官方答复，不能把咨询提交当作持久化已支持。

### 取得环境后的执行顺序

1. **准入**：取得官方适用于本工程资源配置的入口、版本、命令及保存生命周期说明。若需正式原生包，先明确测试客户端、目标设备、同一项目和账号身份、包所含当前程序版本；现有远端旧版本不能代表本机未提交代码。记录设备/客户端版本与实际项目、用户的只读身份，不写入公开反馈。
2. **持久性冒烟**：在同一项目/用户使用唯一独立 b6_* 槽，由现有游戏操作写档；正常关闭，核对真实文件保留，重开新进程恢复同一 revision 和快照。禁止拷回证据、清档、替换 EngineStorage。先过此关再做全流程。
