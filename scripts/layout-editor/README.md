## 启动

在项目根目录双击 **`启动排版编辑器.cmd`**。浏览器将打开 **http://127.0.0.1:18765**。

本机需要 Python 3.10 或更新版本；当前机器已经具备。编辑器运行不需要 npm、安装包或联网。保持启动窗口运行，关掉它会停止保存服务；再次双击会恢复已有项目。如果服务已启动，再次双击只打开同一个编辑器。

也可以从本目录运行：

```powershell
python -B server.py
```

界面按桌面鼠标/触控板排版设计。新页面默认 1080×1920，画布顶部“页面尺寸”可切换 **手机横版 1920×1080** 或 **手机竖版 1080×1920**；各页独立保存。横版预览支持 16:9、19.5:9、20:9，竖版支持对应比例，均为居中裁切检查。

**与游戏方向的区别（2026-10-10）**：上述宽高与 ZIP 导出用于恢复网页排版，不设置 Maker 手机应用方向。当前应用已登记横屏，原竖屏设计的手机交付未验证，见[屏幕方向核查及后续方向决定](../../docs/验证/2026-10-10-maker-screen-orientation.md)。现有页面与素材保留；本次增加网页横版编辑，不改变新页面默认尺寸，不代表已实现自动游戏接入或完成手机实机验收。

## 怎么使用

1. **建页面**：左侧“页面”旁点 `＋`。点击页面名称切换；点击画布上方的名称可重命名。每页单独保存布局，素材库全页共用。
2. **放素材**：上传 PNG、WebP、JPG，点击缩略图加入当前页面。素材多时，在素材列表内滚动鼠标滚轮，或拖动列表右侧滚动条上下浏览；上传按钮和搜索框保持可见。透明 PNG 原始字节完整保存，每次添加都是独立实例。
3. **排画面**：拖动移动；拉四角等比缩放；拖上方圆点旋转。按住 Shift 旋转以 15° 为步长。方向键微调，Shift＋方向键移动 10 个设计像素。
4. **调图层**：右侧列表从上到下对应画面从前到后。拖动整行调层级；眼睛隐藏或显示，锁禁止移动、缩放、旋转、删除及排序。隐藏层仍保留在项目中。
5. **成组**：Shift 点击图层多选，点成组按钮或 Ctrl+G。组内物件、阴影等保持相对关系，整体变换；再次点成组可解组。组保持为连续层级块，不能把别的图层插进组内。
6. **复制 / 删除 / 撤销**：Ctrl+D 复制，Delete 删除实例，Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。删除实例不删原素材。撤销最多保留最近 100 次操作。
7. **预览与备份**：预览隐藏编辑手柄；可下载当前比例的 PNG。**导出项目**得到 ZIP，包含全部页面、原始素材和图层数据，可完整导入恢复。PNG 只供查看。

修改后自动保存；左下角明确显示保存状态。切页、释放编辑权、预览和导出前，会先完成当前页保存。保存期间关闭浏览器会提示尚有修改。

**切换横竖版**：选择画布上方的“手机横版 · 16:9”或“手机竖版 · 9:16”。已有物件保持大小、角度和相对位置，整组按新画布中心平移；包含锁定或隐藏的图层，其属性保持不变。切换作为一次操作支持撤销/重做，不改变其他页面。切换后重新适合窗口；竖版背景不会自动拉宽，画布外的物件仍保留，需要按新构图调整。同页其他窗口实时查看并同步尺寸，取得编辑权后才可切换。

横竖版页面可以共存于同一个项目 ZIP，导入后恢复各自宽高；仅打开旧项目不会自动转换尺寸。预览“原始画布”的横版 PNG 为 1920×1080，选择较长手机比例时按居中裁切区域输出。

## 多窗口规则

- 所有窗口连接同一个本机服务及数据库，约每 1.2 秒检查更新，包含页面名称、素材库与布局。
- **同一页一个窗口编辑，其他窗口实时查看**。点“释放本页编辑权”，再到另一个窗口点“取得编辑权”。不同页面可以分别编辑。
- 正常关闭窗口会释放编辑权；异常关闭最迟约 18 秒后释放。后台被冻结的浏览器也可能失去编辑权，服务端会拒绝旧会话写入。
- 撤销只作用于本窗口当前页的连续编辑会话。切页、释放或重新取得编辑权会清空撤销记录，避免回滚别的窗口的新成果。
- 断线后暂停编辑。保存结果不确定或发生版本冲突时，保留本窗口未保存内容，提供“下载未保存布局”和“载入最新版本”。应急 JSON 只有该页布局引用，用于人工恢复核对，不是完整项目 ZIP。
- 项目导入是替换操作，需要确认；其他窗口仍持有任何页面编辑权时拒绝导入。确认前有新修改也会拒绝，避免覆盖新成果。

## 数据保存位置

```text
scripts/layout-editor/.local/
├── project.sqlite3            # 全部页面和素材原图，持续保存
├── project.sqlite3-wal / -shm # 服务运行期间的 SQLite 日志（可能存在）
└── backups/
    └── before-import-*.zip    # 每次导入前的完整项目备份
```

`.local` 不提交 Git。**迁移或日常备份使用“导出项目”**，它会取得一致的全部页面与素材；运行期间只复制单独的 sqlite 文件可能缺少尚在 WAL 中的数据。关闭服务后，也可整体复制 `.local`。

限制：单张图片最多 30 MB，尺寸不超过 16384×16384 且总像素不超过 8000 万；全部原图最多 250 MB / 3000 张；最多 100 页、每页 1000 个实例，布局数据最多 12 MB；导入 ZIP 及解压内容不超过 300 MB。超限会给出提示。

## 布局格式与 E 接入

ZIP 内包含 `project.json` 和 `assets/<assetId>.<ext>`。当前 `format="to-human-world-layout"`、`schemaVersion=1`、`appVersion="0.1.0"`。

| 对象 | 稳定身份与内容 |
|---|---|
| 项目 | `id`、名称、格式版本；`epoch` 是本机替换世代，防止旧窗口继续写 |
| 素材 | `id`、文件名、原始尺寸、MIME、扩展名、SHA-256、归档相对路径 |
| 页面 | `id`、名称、画布宽高、背景色、`layers`；重命名不改变 ID |
| 实例 | 独立 `id`，通过 `assetId` 引用素材；位置、尺寸、旋转、可见/锁定、可选 `groupId` |

坐标为设计像素，左上角为原点，x 向右、y 向下；实例 `x/y` 表示中心点，`width/height` 为完整原图含透明留白的显示尺寸，`rotation` 为顺时针角度。`layers` 数组**从底到顶**绘制。隐藏层保留数据；`locked` 仅约束编辑器操作。

同 `groupId` 的实例构成连续层级块，变换同时作用于成员。每个成员保存页面坐标中的最终变换，方便 E 直接重放；需要运行时组节点时，可选组中心作为父节点原点，逆变换得到成员局部变换。不把阴影烘焙到背景中；由用户上传独立图片并成组。

E 后续应据页面 ID 和实例 ID 绑定游戏状态/命中区，并按手机安全区制定缩放与裁切。预览中的比例检查是居中裁切示意，**不是引擎 SafeAreaView 验收**。动态正文、数字、词卡文字目前仍应由游戏 UI 实现；本版是图片排版，不提供游戏业务编辑、动画时间轴或自动 Lua 接入。

## 实现与验证入口

- `store.py`：统一 SQLite 保存，页面租约与版本校验，ZIP 验证与备份；不提取归档到任意路径。
- `server.py`：仅监听本机，来源和请求令牌校验，数据目录单进程锁，双击启动复用服务。
- `web/app.js`：串行自动保存、导航、资产/图层操作、撤销与多窗口状态。
- `web/canvas.js`：SVG 实例显示、组合选择与变换手柄。
- `tests/test_store.py`：持久化、复用、租约、冲突、ZIP 与 HTTP 检查。
- `tests/browser.mjs`：真实 Chrome 操作及多窗口验证；测试用独立 `.local/browser-*` 数据，不修改正式项目数据。

```powershell
python -B -m unittest discover -s tests -p test_store.py -v
```

浏览器测试可选依赖，只在要重跑测试时需要：

```powershell
npm install --prefix .local/qa playwright
node tests/browser.mjs
```
