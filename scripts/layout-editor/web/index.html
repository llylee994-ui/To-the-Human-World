页面管理

新建页面

在排版室里

1. 上传素材，点击添加。 同一张图片可放到多个页面，原图始终保存在素材库。

横竖版切换。画布上方选择手机横版（1920×1080）或竖版（1080×1920）。只改变当前页；已有素材大小和角度不变，整体按画布中心对齐，可撤销。竖版背景需要重新构图，不会自动拉宽。预览可检查对应方向的手机比例。

2. 在画布直接调整。 拖动物件移动，拖边角等比缩放，拖上方圆点旋转；按 Shift 旋转可吸附到 15°。

3. 在右侧整理图层。 上面的图层显示在前面；眼睛控制隐藏，锁控制编辑。Shift 多选后成组，物件和阴影一起移动。

4. 自动保存到本机。 等左下角显示“已保存”再关窗口。导出项目 ZIP 可备份全部图片与页面。

5. 多窗口一起用。 同页只有一个编辑窗口，其他窗口实时查看；点“释放本页编辑权”交给另一窗口。不同页面可同时编辑。

撤销 Ctrl Z重做 Ctrl Shift Z复制 Ctrl D成组 / 解组 Ctrl G删除 Delete微调 方向键

浏览器中关闭页面会释放编辑权，异常关闭最长约 18 秒后释放。撤销只作用于本窗口连续编辑期间；切页或重新接管会清空旧撤销记录。导入会替换当前项目，并在本机自动保留导入前的完整备份。
