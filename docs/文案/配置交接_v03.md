轻松后果包括给面包受封、问面包做笔录、喝掉每一勺被编号的汤、研究瓷猫歪脸。夸张发生在 NPC 的行为和梦中，有药效条件，不让面包无故说话，也不把幻觉当案件证据。喜怒哀乐不预设星级；悲伤也可以让诺拉笑着哭一会儿、仍给三星。

已确认的遗忘改变记忆状态；药效结束不自动恢复。N01 同对象冲突本批不永久改写记忆初态。之后新增订单的信任 / 怀疑 / 嫉妒必须声明对象，不能对全世界统一生效。自然入睡之后的梦也不能提前写进尚在柜台或饭桌的直接回信。

## r2 配置修复与正文修订

冻结语义为 **when 全满足；unless 任一满足即排除**。r1 误将两组条件都按全满足理解；本次修复如下：

- `rule_n01_missed_promise_unaware`、`rule_n01_hurt_customer_noticed` 的 unless 只留 recall ≥ 0.6，不再重复排除 when 已要求的 forget。
- `rule_n01_action_dulled` 拆成 recall < 0.6 与 recall ≥ 0.6 且 forget < 0.6 两条互斥规则；新增 `rule_n01_action_dulled_recalled`，两者生成完全相同的强镇静事实。严格小于沿用 `lte`＋`ne`；记忆冲突独占对应结果。
- N01/N02 来信不再复述精确时限；要求栏仍明示原有时间与睡意上限。回信以价牌、椅子、瓷猫与暖碗呈现后果，减少解释药效边界的句子。四处剪词身份、顺序及评分不变。
- N02 面包句的选择表已交到[订单正文](普通订单/N02_两个人的晚饭.md#3-n01-关联短句与可剪词)，尚未运行接入，不能据此勾 F3a。
