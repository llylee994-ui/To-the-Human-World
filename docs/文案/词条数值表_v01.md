## 1. 口径与字段

- 一主属性 1.0＋2～3 个副属性，各副属性 ≤0.2；语义与组合都要有理由。以下 0.05／0.10 是试验档，不是全项目统一定值。
- 来源仅限定稿来信；词必须连续原文、处于加粗区外。回信不供卡。删除旧候选“点头”，原文是“点过头”，不能剪出中间不连续的字。
- 下表“正文段”用于人工定位，从完整来信首段起按空行计数；**不是 `body:N`**。正式 `body:N` 是正文第 N 个可剪标记，选位与标记顺序确认后才能生成。
- 每词有候选 wordId、类别、effects、主词时间 profile；全部 `reusable=false`。最终 `displayText` 必须与标记中文字完全一致。
- 每封 3～5 位先作参考，不能为凑 22 属性覆盖添加词或改定稿。来源缺口先登记，再检查其他自然词位与前信库存。
- 普通词 profile 暂用现行 `daytime_basic`（基础持续 2 小时）；首单睡眠／梦词在 §2.2 明确采用 `sleep_basic` 或 `tired_basic`。速度映射与残留按当前配置，不代表时效已审定。
