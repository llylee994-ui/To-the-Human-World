# 词条数值表 v01（执行版衍射表）

> 2026-10-08 · 数值层第二张表。用途：逐封登记**可剪位置**与其词条向量，供供给验算与配置回填。全文为骨架＋N10 试填，其余待[分支条件表](分支条件表_v01.md)的键位逐单对应后展开；数字全部待定。
> 与配置对应：位置按 `body:N`（来信正文段落序号，按[填写说明](../../scripts/data/填写说明.md)生成）；最终写入 `words.lua` 一类数据时以本表为准。

## 1. 口径

- 词条＝**一个主属性 1.0**（字面能读出来）＋**2～3 个尾值 ≤0.2**；不平均铺满 22 项。
- 类别留在词卡（供玩家粗判），属性数值不写进风味描述；主属性是否可见待 UI 议题。
- 每封来信设 3～5 个可剪位：主轴词必有；各分支键至少各一；多余位补 22 属性覆盖。
- 只在**来信**上设可剪位；回信与分支正文不设。
- 词条一次性；剪下后想什么时候用就什么时候用。

## 3. 展开计划

1. 键位逐单对应并确认后，逐封从定稿来信里选位（N02–N09 按同款试填），并核对 22 属性覆盖不缺项。
2. 与[供给验算表](供给验算表_v01.md)联动：每封各键的可达来源 ≥2 条（本信一张＋先前一张），缺了口回文本补位，不为词造句。
3. 与《数值验算报告》联动：尾值上限与"同属性尾值最多两张词"的约定跑矩阵复核，必要时下调到 ≤0.15。
