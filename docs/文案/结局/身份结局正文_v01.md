## 1. 演出契约与正文边界

主动旅人只在第6～11日有效票、资金足且确认启程时触发；其余普通结算依序学徒→埃德蒙→无名者→未抵达者。只读当前分支正式状态，候选选定后不因终局新增词重算。案件先单独形成结果，身份主稿之后可追加一次案件短段；已播放完整案件结果时只展示其标题／摘要，避免同一长段重复。

身份标题不提前显示在未探索节点上。特别瓶出现前、旅人购买前、封瓶投海前保存节点；没有先生成埃德蒙瓶再改成学徒／无名者的过程。人物正文不告诉玩家点哪个结局按钮或背后的门槛。

土地线修订：案件段之外还须拼接有实际来信依据的土地/救助后续段（L03），保留未兑现、停供或部分返还的差异，不能自动播放统一圆满结尾。五身份正文继续沿用，埃德蒙的承责段按下文更新；L03 全分支正文尚待交付。提前旅人只能读取离场前进展，未抵达者莱恩的过去不改成抢地受害者。

## 2. 无名旅人｜票的另一面

票面／弹窗（界面文字，不写进结局正文）：

> 有效期：6天；第6～11日可购买，第12日停售。剩余天数按当前分支日数计算。
>
> 使用这张票，你将离开魔药铺，结束本次旅程。是否购买并启程？
>
> 确认启程／取消

确认扣300与保存旅人结局是一次原子操作，取消不扣款。保存失败仍停在购买前；不保留已购票再走到别处使用。尚未形成案件结果时另记C04，不在旅人稿泄露真凶。

**结局全文：**

商人把票递给你，翻到背面，又翻回来。他习惯再看一遍日子，好像多看一遍，船就不会先走。

你把门里的灯熄了，钥匙放回它原来的碟子。桌上还有几封信，角被海风吹得微微翘起。你用一只空瓶压住它们。

离岸时，灰港不像来信里那么大。教堂的尖顶、码头的木桩、那些各不相同的窗，都缩成了岸边的一道线。

你还没有想起该去什么地方。船上的人说，先坐下，到了再问。

有人往你手里放了一杯热水。你没有从那句话里剪走任何东西，只把杯子握住。

第一次，你让一段路先于答案开始。

## 3. 魔药铺学徒｜留下来的人

入口：四件固定家居齐全、当前路线全部必需及额外已接订单三星；不要求破案。完整归案时也优先本稿，不送埃德蒙瓶。错抓／逃脱／未解的案件段保留现实代价，不让店主认可替警备宣布案件正确。

**店主认可便笺：**

> 窗帘别总拉到底，白天能省一点灯。壁炉里的灰明早再清，今晚先坐一会儿。
>
> 书架上那本没有名字的簿子，留给你。不是每封信都能照你想的样子结束，至少收到它的时候，别只看报酬。
>
> 钥匙不用放回来了。
>
> ——上一任店主

**结局全文：**

你把便笺夹进簿子，没有立刻翻到下一页。

床铺终于不再被拿来放空瓶。书架最下层仍有一点歪，你拿一张旧纸垫了垫。炉火映在窗帘上，像远处的一扇有人开着的窗。

这里的每样东西都花过钱，也占过你一天里的一小会儿。直到此刻，你才发现，自己早已替明天留好了位置。

来信仍会有难办的事，灰港也没有因为一间铺子整齐就变得公平。有的人会再写，有的人未必肯说第二遍。

你把桌上最后一只瓶子擦干，放在离炉火远一点的地方。

门外的潮声和第一天一样。屋里多了一把由你留下的钥匙。

## 4. 埃德蒙｜自己的字

入口：克莱拉实际归案、学徒未达、到身份结算。本篇只拼C01案件短段；不因为“猜中了”或抓运输案嫌疑人触发。

**终局旧信（埃德蒙与未抵达者共用同一全文）：**

> 收信的人：
>
> 这些年我一直以为，只要愿意听，人们自然会把事情告诉我。
>
> 最近我开始{{怀疑}}，我听见的也许只是别人允许我听见的。柜子就在书房隔壁，几户人家的住址，我竟到昨天才第一次认全。
>
> 如果还有什么是我不知道的，我愿意把它看完。即便那里面也写着我的名字。
>
> 埃德蒙·维尔
>
> 灰港 白榆街17号 书房窗下

特殊稳定位置body:1怀疑／word_doubt。埃德蒙演出尝试剪词失败，不产生实例；独立界面提示为“你不能从自己的信中取走词语。”这是反馈，不让信中人物解释剪词规则。随后接全文；不熬此信、不收费或评星。

**结局全文：**

纸的边角没有裂开。

你认出了那个写得比旁边字稍长的“我”，也认出了末尾那道总收不住的横。并不是署名先告诉你答案，是手先想起了写字的人。

埃德蒙·维尔。

桌上没有给这个名字腾出一张好看的椅子。那些转款、被裁下的地址、始终没送来的话，仍然一张挨一张摆着。

你听见过那个人在门外说抢地。那时你让人拿旧契据给他看，好像纸上签过字，就等于拆屋之前，每个人都愿意离开。

如今那些纸重新摆在面前。你自己的签名也在上面。接收土地、收取租金的时候，你已经足够大，知道一个名字落在纸上，意味着谁能留下，谁必须走。

后来送出去的煤曾让人熬过冬天。那是真的。被拆掉的屋子，也不会因此重新长回原处。

克莱拉要为那个下午负责。那些更早的日子，也不会因此从你身上脱落。

你把自己的信放到末尾，第一次没有把别人的纸让到后面。

有人愿意收回欠他的东西，也可能一辈子不愿意再说你的名字。这一次，你没有替他写下该怎样原谅。

潮水退下去，桌上所有住址都能看见了。

## 5. 未抵达者｜正确的地址

入口：未达学徒、真凶未归案、无名者词条门槛未达，作为保证可结束的兜底。先收到上一节埃德蒙对照信，剪body:1怀疑成功；本次新词不重算身份资格。随后必达个人求助记录，无隐藏证据前置。

**个人旧求助记录：**

> 自我介绍：我叫莱恩·贝尔，替街坊修鞋，也补小件皮具。和母亲住在铁锚巷，屋里不大，门外有一口旧井。信是我自己写的。
>
> 维尔先生：
>
> 我不想把屋子里的炉子烧得很旺，只想能在天黑以后再点一会儿。母亲的被子潮了，我烘到一半，煤已经见底。
>
> 上次听人说冬天的物资要先登记，我来登记。我能做的活仍做着，您若需要修东西，也可以一并捎来。
>
> 门牌没坏，二十七号，一层临井的窄门。我白天就在门旁修鞋，要是没碰见我，留一张收货条，我会照着去领。
>
> 莱恩·贝尔
>
> 灰港 铁锚巷27号 一层临井窄门，门旁鞋摊收
>
> 接收批注：姓名与住址已核对；暂缓／未递交。

此为莱恩的个人旧求助记录，姓名和地址与M07/K42区分，不冒充原举报。同一截留流程涉及不同人的信。本记录没有写错地址，不能把被截留归因于玩家填错。记录无剪词或订单报酬；阅读后以本人的生活记忆确认过去，独立于是否曾拿到K42证据。

**结局全文：**

埃德蒙信上的词落进你手里。随后那封更薄的纸，却让你停了很久。

你记得井边刮进门缝的风，记得把一双鞋翻过来，躲着阴影缝最后一针。母亲问炉子还能不能烧，你说快好了，像在说那双鞋，也像在说整个冬天。

莱恩·贝尔。这个名字没有被改过。门牌也没有。

纸到了收件台，到了柜子，到了“暂缓”那一栏，就是没有到你等的人手里。

那些年，你总怀疑自己是不是写得太长，是不是该把地址再描一遍。现在你伸手，把那处已经清楚得不能再清楚的“二十七号”轻轻抚平。

这一次，你没有再等柜子里的人说可以。

你的信放在灯下。从第一行到最后一行，都被读完了。

## 6. 无名者｜我想

入口：非学徒、未归案、confirmedPast=false，正式可用库存至少12个定义／5类。直接特殊愿望瓶，不出现埃德蒙或莱恩记录。姓名与地址空白是本特殊信的设计，不改变普通来信格式。

**特殊信全文：**

> 你的愿望是什么？
>
> 我想……

作者交接：至少拼一个当前分支可用词，预览时保留所选词顺序与重复实例规则；封瓶前可改。移动引用不复制库存，封瓶与保存原句原子提交，投海后进入全文。没有给自己熬药、付原料、发货或星级。预印“我想”不要求玩家新获得这两个词。

**结局全文：**

这封信没有叫出一个你能想起的名字。

你把一路留下的词放到纸上。有的来自一顿饭，有的来自一次迟疑，有的曾被人用力写过，剪下来后，边仍不很整齐。

最后一个词放稳，你把整张纸摊开。句子也许短，也许有一点拗口。你没有把它换成别人的说法。

纸进了瓶子，瓶塞旋紧。你走到潮水刚碰得到的地方，松开手。

瓶子没有立刻漂远，先在脚边转了一圈，像还想把那一句再读一遍。

（此处拼一段下表的语义回应。）

下一道浪来了。海上多了一只装着你愿望的瓶子。

### 愿望语义回应与通用兜底

只看词定义ID，不读药效值或隐藏身份分。拟定主题表如下；每个ID仅属于一组，必须所有选词落在同一组才用该组回应，跨组或无法归组使用通用。不会因为解析不出标准句阻止投海。数据结构待程序冻结，不把此表直接塞入当前Narrative模板。

| 主题／全部选词属于该组 | 文案回应 |
|---|---|
| 休息：睡觉、梦、安静、累、放松 | 岸边的灯渐渐低下来。你第一次替自己留了一段可以慢一点的时辰。 |
| 相见：回家、想念、答应、信任 | 你还不知道这句话会漂到哪扇窗前。至少今天，它有了向海的第一步。 |
| 身体：手稳、疼、温暖、安心 | 风仍吹着，手里的空处却没有刚才那么冷。你把自己的那一份感觉，也放到了纸上。 |
| 心绪：快乐、笑、生气、难过、嫉妒、害怕 | 这一次，句子里那些轻的、重的感受，都没有被你剪掉。 |
| 吃饭：饿、面包、汤 | 你想起过许多人的饭桌。如今那张很短的纸，也给你留了一个位置。 |
| 探索：勇敢、抬头、理性、好奇、怀疑 | 海的那一边仍看不清。你已经把第一句放出去了。 |
| 通用：跨主题；忘记／茫然／等；其他不能可靠归组的合法句子 | 你没找到能证明过去的那一封，便把今天的这一封放进了海里。它不是谁替你留下的，是你自己愿意寄出的。 |

覆盖全部30定义；同一主题多词只拼一次回应。混合“回家＋忘记”不能武断改读成“想重逢”，使用通用并保留原句。“没有可确认过去”不等于已证实从未活过，正文不宣布新本体真相。
