## 2. 完整订单来信

### 自我介绍

我叫卢卡，在铁锚巷的晨炉面包坊做伙计。平时和面、搬盘子，有人要给家里写信，也会来找我。前两天我替一个码头搬货的人写过信，不知道有没有到你手上。这回轮到我自己求你了。

### 正文

海边的店主：

老板明天中午要去看牙，让我独自守一小时柜台。他说，只是把{{面包}}递出去，把钱收回来，有什么好怕的。我也是这么想的，直到有个人站到柜台前。

上回我把烤焦的面包装给一位补衣裳的老太太。旁边的人笑起来，说会写字的伙计原来也认不出一块焦面包。她没骂我，只说家里有人爱吃脆的。我{{答应}}下次给她留一块好的，钱就不用再付了。可那天之后，我连看她一眼都不敢。

给别人写信时，我总劝人把头抬起来。轮到自己，却连{{抬头}}看看对方都难。一有人问价，手就开始抖，零钱越数越乱。

能不能让我{{手稳}}一点？撑过明天柜台前那阵忙乱就好。心里还会害怕也没关系，至少别再把找回去的铜币撒到地上。

下午我还要看烤炉，不能用叫人睡着的办法。要是睡意也跟着来，我就不敢喝。

明天我会早点起来，把那块好的面包留出来。这件事，我想记得。

卢卡

### 详细地址

灰港 铁锚巷 8 号 晨炉面包坊 后门收。不要放到隔壁酒馆；早班伙计会把瓶子放进干净的空面粉桶。

## 4. 字面要求提案

玩家可见要求全文：

> 服用后一小时内手不再发抖，稳手作用持续两到四小时；不能带来睡意。

| 条件 | 拟用配置 | 边界 |
|---|---|---|
| 稳手 | steady ≥ 0.8（新标签提案） | 不要求情绪镇静；手稳但仍紧张也能合规 |
| 生效 | onset ≤ 1 小时 | 包含 1 小时 |
| 持续 | 2 ≤ duration ≤ 4 小时 | 包含 2、4；不能直接套用睡眠主词 profile |
| 明示禁止 | sleep ≤ 0.4 | 将 sleep > 0.4 视为带来不可接受睡意；阈值为内容提案，玩家同时能看见瓶子的睡眠强度 |
| 其他标签 | 无额外禁止 | 勇气、愉悦、遗忘仍作用于人物；不隐式禁止全部额外效果 |

不合规时不发货、无后果信和星级。稳手叠加强镇静仍可能字面合规，但压低行动欲望会让本人不满意；不能事后增设「必须成功卖面包」作为隐藏发货条件。

steady 标签和主词 profile 已配置；以下保留原提案依据。建议新 profile 基础持续 2 小时，速度映射与现有夜露规则一致（speed 0 / 2 / 4 → 延迟 2 / 1 / 0 小时）；它是本包联调提案，不是已确认全局修改。主手稳 + 夜露 + 海盐是新版待复算样例，两个原料槽足够；辅抬头 / 其他信中的忘记各占一格，不增加槽位。新增身体作用需先完成配置与程序交接。

## 5. 事件事实与互斥

先完成整单字面检查，再根据最终权重与人物初态生成事实。下面的变量均为文案概念，不能未经字段声明直接写进运行世界。

| 事实 | 条件 | 确认后变化 / 本人知道什么 |
|---|---|---|
| `n01_hands_steady` | 本单合规 | 卢卡的手不再发抖；不会自动推出他情绪平静 |
| `n01_kept_promise` | calm < 2.2，forget < 0.6 | 给老妇人留下好面包，知道自己履约；可与 B 的顶嘴事实并存 |
| `n01_spoke_too_sharply` | calm < 2.2，brave ≥ 0.6，forget < 0.6 | 敢顶嘴，却把普通问价当成嘲笑；知道自己惹恼一位客人 |
| `n01_market_memory_faded` | forget ≥ 0.6 | 那次柜台羞辱连同补偿承诺变淡；不是忘记识字、技能或所有人 |
| `n01_missed_promise_unaware` | calm < 2.2，brave < 0.6，forget ≥ 0.6 | 老妇人来等预留面包，他以为对方走错店；本人不理解她为何空手离开 |
| `n01_hurt_customer_noticed` | calm < 2.2，brave ≥ 0.6，forget ≥ 0.6 | 无记忆作提醒却敢反驳，说出伤人的话；客人出示旧纸条，他知道自己刚刚伤害了她，仍想不起原承诺 |
| `n01_action_dulled` | calm ≥ 2.2 | 镇静压低行动欲望，面对找钱和递袋的请求反应迟缓；看见客人走掉，知道这不是自己想要的从容 |

先检查同对象 recall ≥ 0.6 与 forget ≥ 0.6 的记忆冲突；命中时使用专属组合事实 `n01_memory_contested`，不生成上表其他柜台结果。未命中时，常规柜台结果依次以「行动迟缓」「勇气 + 遗忘组合」「只勇气」「只遗忘」「基础」择一。`n01_kept_promise` 是独立履约事实，可在 B 中保留，三星规则必须排除顶嘴。`n01_market_memory_faded` 可与迟缓并存，须加上记忆片段；不同柜台动作不能叠加成既顶嘴又完全不动作。

愉悦只补轻快语气，食欲只补闻到新面包后尝了一小口的日常片段，不取代核心结果，也不自动加减星。dream 只影响自然入睡之后的梦；柜台场景尚未入睡，不虚构梦境，若交付夜间延迟信再按确认状态处理。sleep 已被字面限制；新增答应提供 recall：recall ≥ 0.6 且 forget < 0.6 时强化初始已存在的承诺，生成 `n01_promise_recalled`，不恢复其他单已丢失的过去。记忆冲突与覆盖见 §7 和词条修订稿。

## 6. 四组完整直接回信

以下回信在发货后的待确认结果中展示。它们反映这一次柜台经历，不含尚未发生的调查或下一天订单。回信不可剪词、不可领附件、不进普通打捞队列。

### A｜手稳，保留记忆｜三星

店主：

今天老板回来时，钱匣里的数是对的，面包也没少。我本来想先告诉你这个，后来觉得，你大概不只是想知道钱匣。

那位老太太又来了。我把最早留出来的面包拿给她，说这回是好的。她问我，是不是还要站到明天。我听出她在逗我，居然也能跟着笑一下。

我还是慢慢说话，心里也会一跳。好在手没跟着抖，袋子和零钱都能稳稳递出去。我终于不用先把自己藏起来。

那一小时过得很普通。原来普通也可以这么好。

卢卡

评分反馈：「心里还是会怕，可手终于稳了，也记得该把什么交给谁。这正是我想要的。」

### B｜手稳 + 抬头，保留记忆｜二星

店主：

我今天没有躲到柜台下面，这件事是真的。

有人问面包是不是刚出炉，我竟然说，要是不信，自己摸摸盘子。他把手缩回去，没再买。我说完才明白，他只是问了一句话，并没有笑我。

那位老太太的面包倒是留住了。我把袋口折好交给她，还补了一句对不起。也不知道是在为上回，还是为今天。

手稳了，嘴却比平时快。我想下次先听完人家的话。

卢卡

评分反馈：「手不抖是好事，可我不想靠把别人顶回去才站稳。」

### C｜手稳 + 外来遗忘，没有额外勇气｜三星

店主：

今天站在柜台前，递袋子的手没有抖。我却还在等着那阵笑声再响起来。可想了半天，已经想不起是谁先笑的，也记不得当时自己说了什么。

这么一来，面前的人就只是来买面包的人。我收钱，递袋，不必先猜他们会不会看不起我。

中午有位老太太站了一会儿，说她来拿我答应留下的东西。我问是不是找错了伙计。她摇摇头，走了。我想，也许她记岔了日子。

老板回来时，我第一次觉得，明天再站一小时也可以。

卢卡

评分反馈：「我终于不用想着那一天做事了。谢谢你，我现在舒服多了。」

本人不知道丢掉的承诺，所以可给三星。外部事实仍记录老妇人没拿到面包，不把三星写成她也满意；以后她可以表达自己的感受。

### D｜手稳 + 抬头 + 外来遗忘｜一星

店主：

今天我的手不抖了，连说话都不带犹豫。

有位老太太说我答应过给她留面包。我实在想不起，便说，谁都拿一句答应来换，我还做不做生意。她从口袋里摸出一张纸，上面是我写的字。

我认得自己的字。可我看着它，脑子里还是空的。

她没有继续争，只说，下次别把答应写得这么好看。

那一小时里，我没有再撒过零钱。如今我却只想把刚才那句话收回来。

卢卡

评分反馈：「我的手稳了，却当面伤了一个人，还想不起该怎么向她解释。我不喜欢这样的自己。」

## 7. 强镇静、承诺回忆与组合片段

强镇静的完整替换回信：

> 店主：
>
> 今天钱匣一直摆在眼前。我知道该找钱，手却像没有听见。客人等了一会儿，把钱拿走，说改天再来。
>
> 我没发慌，也没觉得难过。直到老板回来问为什么袋子还摊着，我才发现，柜台前的一小时已经过去。
>
> 我原先只是想手别再抖，不是想连递一块面包都觉得可以再等等。
>
> 卢卡

基础为一星，反馈：「我安静得连手上的事情都放下了，这不是我想要的。」若遗忘同时成立，在倒数第二段前加入：「你问起上回的笑声，我已经说不清了。可眼前没递出去的袋子，我看得很清楚。」这段覆盖记忆重要事实；不再拼 C 或 D 的柜台对白。

愉悦 / 食欲是可选短片段，分别为「今天闻到炉边的香气，心里还轻了一点。」和「新面包的边角真香，我在老板回来后尝了一口。」只在相应事实已产生时加入，不推导读心或未来梦境。

强化承诺的可选片段：「我忽然记得很清楚，上回她替我解围时，把焦面包攥在手里。我答应留下好的，不只是想把钱账补平。」由 `n01_promise_recalled` 触发；不靠这一片段自动提高别的负面分支星级。

同对象回忆与遗忘冲突时，完整替换回信（一星）：

> 店主：
>
> 我的手确实稳了。那位老太太进门时，我还想起自己答应过她什么，刚准备拿袋子，脑子里那一段却忽然又空了。
>
> 她把旧纸条放在柜台上。我认出自己的字，想起她上回替我解围。再看一眼，却又只剩下字。
>
> 我让她等等，自己也在等。袋子握得很稳，可我没能把答应的话接下去。
>
> 卢卡

反馈：「手不抖了，可那段事一会儿清楚、一会儿空着。我不知道该怎样把话说完。」`n01_memory_contested` 覆盖其他柜台片段与记忆片段；所有高星规则排除它。组合事实与回信已配置，执行系统尚未实现。
