## 人物与纠结

卢卡22岁，在面包坊干了四年，会识字，也替街坊写家信，但没有正式抄写和记账的训练。他话多、爱解释，习惯给别人留面子，被轻视后又会生气。街坊认可他的字，让他开始盼着靠这门本事谋生。

面包坊给他熟悉的活计、工钱和楼上的住处，老板还曾照顾过他；做学徒眼下钱少，却能学到一门自己想做的手艺。他担心离开后没着落，也不愿被说成忘恩负义，更希望老板承认他这些年有长进。纠结不只在于怕吵架，还在于舍不得照顾自己的旧关系，又不甘心一直被当作什么也不会的孩子。

| 分支 | 情节概要 |
|---|---|
| 1．谈妥离职 | 卢卡说清自己已经决定，主动提出再留一个月、工钱照旧，把新伙计带熟再走；老板仍不认可他的选择，但把交接的事说定了。抄写员那头还有行会推荐的人排队，只肯多等他这些天。他失落地发现自己一直盼着一句夸奖，最后还是定下离开的日子。 |
| 2．吵翻搬走 | 老板指责他忘恩负义，卢卡忍不住争辩自己四年的付出，当天收拾东西搬走。抄写员让他暂住后屋、次日开工；他还在生气，也后悔说了伤人的话，想等气消后道歉，学徒还是要做。 |
| 3．加薪留下 | 老板提出加薪到与学徒相同的工钱，并答应教他记账，卢卡觉得终于被重视，选择留下。回绝学徒机会后，他回到屋里，把床板底下那几张字又塞了回去；老板又把教账推到明天，他开始不踏实，打算再问一次。加薪和教账都还只是承诺。 |
| 4．两边应承，错过机会 | 卢卡答应老板教会新伙计再走，又给抄写员回了话，说很快就到，可两边的日子被他记岔了。到了那天他还脱不开身，抄写员那头行会荐来的年轻人接了位置；他留在面包坊，难堪地承认这次机会是自己拖没的。 |
| 5．承认不会，留下学习 | 卢卡憋着被老板看轻的气，去见抄写员时急着证明自己，想早些独立接活，却连正式文书都读不明白。他羞得想遮掩，最后还是承认不会、开口请教，从第一行开始学。 |
