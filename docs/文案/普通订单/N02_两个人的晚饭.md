## 2. 完整订单来信

### 自我介绍

我叫诺拉，在铁锚巷补衣裳。窗口上放着一只缺耳朵的瓷猫，找得到猫，就找得到我。儿子叫艾文，在船上做木工，明晚靠港。我已经把他从前那把椅子擦过两遍了。

### 正文

店主：

我不常求这些东西。针断了换一根，衣服小了放一道边，总有手上能做的事。

可两个人隔着桌子坐下来，有些话就不知道从哪里拆起。

艾文明晚{{回家}}。两年前他走的时候，我们吵得很难看。我总说城里有份正经活，他总问，为什么他想去的地方就不正经。最后我答应他，下次回来，只吃饭，不替他安排。话是我自己说的，这两年却总在心里反悔。

我想明晚能对他{{笑}}一笑。不是把两年前说成没有发生，只是别等他还没坐下，就先摆出一张讨债的脸。

我已经买了面包，准备炖一锅{{汤}}。他小时候等饭会喊饿，我那时嫌吵，现在倒希望门外再有人喊一声。

邻居说，孩子回来了，过去的事能忘记就忘记。我没接话，只把多余的一把椅子搬进去了。

我想在他敲门前，心里先轻快一点，够我们慢慢把晚饭吃完。锅还得有人看着，可别让我打瞌睡。

要是吃饭的时候能{{等}}他把话说完，不急着问他挣多少、几时回来，就更好了。

我不知道现在的他还爱不爱喝那种汤。先少放一点盐吧。

诺拉

### 详细地址

灰港 铁锚巷 14 号 一层 临街补衣窗口收。窗口关了就从门缝塞一张收货条，不要把瓶子留在门口台阶上。

「收货条」指人间配送方已有的投递行为，不让玩家写字或主动发送调查信。

### 收取时机与稳定位置

N02 **成功收取时**，读取当时的已确认事实，选定 variantId 和整封正文，并将二者随该信件实例保存。重复收取或打开信件沿用已保存正文。后来确认 N01 不重写已收到的 N02；回溯恢复的是该分支保存的实例，不取另一分支的 pending 或历史最佳评分。

所有六行共享剪词约束：`body:1 回家 / word_homecoming`、`body:2 笑 / word_smile`、`body:3 汤 / word_soup`、`body:4 等 / word_wait`。每行仅替换含汤的原句，既有其余三处保持一次且顺序不变；每个变体重新解析字节范围，不能复用默认句的偏移。正文修订按内容版本处理，不静默替换已保存实例。

待 P6 确认：变体定义的文件和字段、读取已确认事实的接口、信件实例存储 variantId／renderedText 的结构。当前不向正式配置塞入未知键。正反例：履约＋嘴快→kept；遗忘且不知失约→missed；伤人已见→hurt；记忆冲突→contested；强镇静→dulled；仅基础／趣味事实或 N01 未确认→default。变体只回收日常因果，不改 N01/N02 星级。

先校验正式归档的事实互斥，再选变体；损坏档案里若同时出现互斥事实，应报错，不能靠优先级吞掉。上表优先级用于合法条件相交时的确定选择。

| 正文位置 | 词 | 新定义提案 / 类别 | 含义 |
|---|---|---|---|
| body:1 | 回家 | `word_homecoming` / 关系类 | recall 0.6 + dream 0.4，唤起已声明的家的记忆，不召回或传送别人 |
| body:2 | 笑 | `word_smile` / 行为类 | happy 1.0；愉悦不自动修复关系 |

四个新词各有生活语义，定义与作用边界见[词条多样化修订](../词条设计_多样化修订.md)。不再重复剪快乐、饿、忘记和安静；旧信所得词仍可带来相应药效。新关系 / 物件 / 时间词需正式定义与投放验证，不能只通过改类别算无名者达标。

## 4. 玩家可见要求与时间提案

> 一小时内感到轻快，愉悦持续两到四小时；不能带来睡意。

| 项目 | 条件 |
|---|---|
| 主轴 | happy ≥ 0.8 |
| 发作 | onset ≤ 1 小时 |
| 时长 | 2 ≤ duration ≤ 4 小时，含边界 |
| 明示禁止 | sleep ≤ 0.4；超过此阈值不发货 |
| 未明示禁止 | calm / brave / forget / appetite 等允许存在并产生后果 |

「安静听他说话」是她对饭桌的期待，通过事实影响满意度；不是未写进要求的额外发货门槛。保留承诺也不是明示禁止遗忘，所以遗忘分支可以字面合规而低星。

建议给新词笑补 happy profile 基础持续 2 小时，speed 0 / 2 / 4 对应延迟 2 / 1 / 0 小时，与 N01 一起联调。新词笑和既有快乐均已定义 profile；实际合成尚待实现，不借用睡眠 8 小时。

## 5. 直接事件事实

初始场景为诺拉与儿子确实按约见面。饭桌上的变化由本单药效触发；不为低星分支临时让儿子无故爽约。

| 事实 | 条件 | 结果与本人认知 |
|---|---|---|
| `n02_mood_lightened` | 本单合规 | 她不再一见儿子就板着脸，知道自己心里轻快 |
| `n02_promise_kept` | forget < 0.6 且 brave < 0.6 | 记得「只吃饭、不安排」；儿子愿意继续说船上的生活 |
| `n02_shared_appetite` | appetite ≥ 0.6 | 诺拉把碗里的汤吃完，与儿子多分了一块面包；不把母亲药效隔空传给儿子，儿子参与是对饭桌气氛的自然回应 |
| `n02_argument_memory_faded` | forget ≥ 0.6 | 最后争吵与当时承诺模糊；没有忘记儿子姓名、整段亲情或煮汤技能 |
| `n02_old_arrangement_repeated` | forget ≥ 0.6，brave < 0.6 | 又提起替儿子在本地找活；儿子提醒原承诺，她知道两人之间有件事没被她记住 |
| `n02_overstepped_apologized` | forget < 0.6，brave ≥ 0.6 | 太敢开口，开始安排他明天见人；听见提醒后记起承诺，当场道歉，愿望实现但有遗憾 |
| `n02_forced_future_hurt` | forget ≥ 0.6，brave ≥ 0.6 | 坚持要儿子按自己的安排留下；儿子出示旧信、提前离席，她看见饭桌坏了，知道自己没有听他 |
| `n02_listened_patiently` | calm ≥ 0.6 且 calm < 2.2 | 她让儿子把话说完；有遗忘时也不能自动恢复承诺 |
| `n02_response_dulled` | calm ≥ 2.2 | 情绪轻快但回应意愿低，儿子问话时她长期不答；本人在他告别时发现自己几乎没参与这顿饭 |

核心饭桌事实依次选「回应迟缓」「勇气 + 遗忘」「只勇气」「只遗忘」「保留承诺」。食欲、记忆变化与适量倾听是兼容片段，不能将两种饭桌结局同时拼出。

dream 若在自然入睡后产生，另作延迟内容，不提前写进饭桌回信。sleep 超过明示上限则本单失败。回家新增 recall 来源，只作用于 `mem_home_table`：儿子小时候在门口等汤的记忆。最终 recall ≥ 0.3 生成 `n02_home_recalled`；忘记仍作用于两年前争吵的 `mem_last_argument`，两者不是同一对象，不自动恢复已丢失的承诺。

## 6. 四组完整直接回信

### A｜笑，保留承诺｜三星

店主：

艾文进门时，先说椅子是不是太小了。我差点回一句，人还没坐下就挑东西，后来自己也笑了。他现在比走的时候宽了一圈，当然嫌小。

他讲船上的床窄，夜里有人翻身，整排木板都会响。我听了好一会儿，才发现我没问他赚多少，也没问下一趟要去哪里。

汤喝完了，他把两只碗一起洗了。临走问我，下次还做不做这个。我说，你来就做。

以前我总想留住他。今天才知道，一顿饭也可以只是一顿饭。

诺拉

评分反馈：「我笑得出来，也记得答应过什么。今天我们总算好好吃了顿饭。」

### B｜笑 + 汤，保留承诺｜三星

店主：

艾文进门时，先说椅子是不是太小了。我看了看他，也笑了。

原先我总在他吃饭的时候忙来忙去，问他要不要再添，自己那碗却放凉。今天我坐下来，把汤喝得很干净，连面包都多分了一块。

他问是不是下午没吃东西。我说，我也不知道，今天就是觉得饭好吃。他便讲起船上有一位师傅，能把任何东西煮成同一种味道。两个人说着说着，把最后一点汤也分了。

我没问他下一趟去哪里。临走时，他说，下次多炖一点。

两只碗都空着，桌子却不像从前那么空了。

诺拉

评分反馈：「不只是看他吃，我也好好吃了一顿。多出来的胃口，倒把我们留在了同一张桌子旁。」

食欲改变的是诺拉，儿子多吃并非被隔空施药。本包不把「额外效果」一律写成代价。

### C｜笑 + 外来遗忘，没有额外勇气｜二星

店主：

我今天没有板着脸。艾文讲起船上的事，我还问他，能不能顺便修一下窗口那块木板。

后来我说，隔壁铺子正缺人，他明天可以去看看。他放下勺子，说，我们不是讲好了，不谈这个吗。

我想了很久，想不起什么时候讲好的。他没有再争，只说算了，今天汤很好喝。

我们把饭吃完了。心里那块硬东西确实轻了些，可他看着我的时候，我忽然不知道自己少记住了哪一句话。

下次我先听他说吧。

诺拉

评分反馈：「今晚比以前轻松，可我连答应他的事也记不清了。要是能留下那一句，就好了。」

### D｜笑 + 外来勇气 + 外来遗忘｜一星

店主：

我今天一开口，竟然没有一点犹豫。我告诉艾文，铺子的活我已经替他问过，明早就能去。

他说不去。我还笑着说，总不能一直在海上飘。他从衣袋里拿出一封旧信，放在汤碗旁。我认得自己的字，上面写着，下次回来，只吃饭。

他问我，这句话现在还算不算数。

我不知道怎么回答。心里明明还是轻快的，桌子对面却已经不是我想要的样子。

他没有喝完汤。走的时候，椅子也没往里推。

我本来只是想给这顿饭一个好开头。

诺拉

评分反馈：「我笑着把他又推远了一次。这种轻快，我宁愿没有。」

## 7. 其他合规组合的模板片段

只勇气、没有遗忘的二星完整回信：

> 店主：
>
> 今晚我把好些平时不敢说的话都说了，连明天该替艾文见谁都安排到了一半。他问我，还记不记得那句只吃饭。
>
> 我记得，便把话停下来，向他认了错。他没走，我们后来还说了些船上的事。可刚开头的时候，我到底又拿自己的打算盖过了他。
>
> 我已经能笑了。下回还得学着少说一点。
>
> 诺拉

反馈：「幸好我还记得，能及时道歉。今晚有好的一面，也有我不满意的一面。」

强镇静的一星替换回信：

> 店主：
>
> 艾文问我汤里放了什么，我笑着点头。后来他又问，窗口的木板是不是要补，我还是点头。我知道自己听见了，只觉得开口可以再等一会儿。
>
> 等他起身，我才想起来，还没问过他一路冷不冷。他说改天再来，我不知道他是不是也觉得，今天没什么可说的。
>
> 我心里轻快，却像把自己留在了饭桌外面。不是这把椅子小，是我没坐进去。
>
> 诺拉

反馈：「我没有板着脸，可也没有好好回答他。我想要的不是这样一顿饭。」若遗忘同时成立，加入：「那封旧信里的承诺，我也已经想不清了。」覆盖记忆事实，不拼 C、D 的另一组对白。

适量镇静的可选片段：「他说话时，我能等他把最后半句也说完了。」只放入与当前饭桌结果相容的位置；D 里即便听完仍坚持安排，也不能因此自动改为三星。

食欲片段遇低星仍可出现：「我今天确实把汤喝完了，只是桌子对面的话没能跟着留下。」它不能覆盖关系结果，也不能让高食欲把一星抬成三星。

回家回忆的可选片段：「他说船上的锅总有一股旧木头味，我忽然想起他小时候，一听见我搁勺子，就搬着椅子往桌边挪。原来他已经很久不用我抱上椅子了。」由 `n02_home_recalled` 触发；不替代当前承诺与关系结果，不能把 C 或 D 自动改成三星。夜间梦境另交延迟信，不在饭桌场景提前发生。

## 8. 评分依据与覆盖规则

## 9. 配置与验收交接

已配置的基准配方：主笑、夜露 + 海盐；A 无辅助、B 辅汤、C 辅首单剪来的忘记、D 辅 N01 的抬头 + 首单忘记。另有辅等 / 回家的片段覆盖。回家辅助 recall = 0.36、dream = 0.24，可达到家中回忆阈值 0.3。以上在 r2 经正式 Potion／WorldState／Narrative／Order.Rate 核对，完整事务仍待 P2/P3。

N02 可独立出信，不要求 N01 完成；已有主流程需要把 N01 的抬头当勇气药效的一种可达来源，并检查整路线的词条获得。N01 未完成时不能宣称 D 已可熬，也不让未取得的词凭词库存在自动进库存。

`mem_home_table`、家中回忆阈值及独立争吵对象已配置，联调须核对对象互不混用。还需覆盖：happy 阈值、2 / 4 小时边界、sleep 禁止上限、forget / brave / appetite 的 0.6 边界、calm 2.2 的迟缓替换、记忆及组合片段覆盖、同额奖励、重置不留星级、回溯不保留另一分支的面包短句。

强镇静规则边界与玩家可达配方分开验收；不能沿用旧八词基线对当前 30 词包作不可达判断。旧锅槽位、原料修正、时间要求和睡意上限共同决定可达性，由程序侧按当前输入枚举核对，不靠扩充词定义直接宣称可达。

正文换版本时冻结 `body:1～4` 与 NPC 记忆对象。N01 关联优先用接收信件时的当前正式状态选定正文，再随存档保留；不要每次打开已收到信件都按最新世界重新改写过去。
