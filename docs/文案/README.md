## 交付顺序

1. [主线节点表](主线/寄往人间_主线节点表_v01.md)：先检查因果、线索顺序、成对选择与各条路线可达性，再逐节点扩成信件正文。
2. [N01 柜台前的一小时](普通订单/N01_柜台前的一小时.md)：普通订单的模块化回信样板，遗忘可以让本人满意，也会影响别人。
3. [N02 两个人的晚饭](普通订单/N02_两个人的晚饭.md)：额外食欲可以带来好结果，遗忘也可能破坏关系；与 N01 共用规则风格，人物态度不同。
4. [词条多样化修订](词条设计_多样化修订.md)：两单各四个新词；区分生活语言、已有药效与新增身体作用，列明记忆对象与接入需求。
5. [词条与 NPC 覆盖规划](词条与NPC覆盖规划.md)：核对喜怒哀乐、茫然 / 理性 / 放松，列出首版 30 词候选池和八位补充人物；30 个词定义已落盘，八位补充人物仍未交付完整订单。

主线表中的来信摘句是写作锚点，不冒充全部主线正文已交付。两个普通包的来信与 A～D 回信则是可以直接审读的完整正文。

## 写作约定

- 来信写人物的处境、愿望与生活，回信写做了什么、别人如何回应；减少解释游戏规则的文字。精确时限与禁用药效集中写在玩家可见要求栏，阈值、槽位、确认／重置等放交接说明，不在人物信里重复讲解。
- 药效边界保留在词条／效果定义与作者说明里。正文用行动和场景表达，避免反复解释“没有真的变出东西”；保留推知后果所需的线索和人物误解，轻松、夸张的后续仍须与事实相容。
- 玩家留在魔药铺。调查信息来自漂流瓶、回信和附件；不新增主动询问 NPC 的功能。
- 固定真凶是克莱拉；新分支改变信息与人物行动，不能改写案发事实。
- 普通正式订单包含自我介绍、来信正文、详细地址。`{{词}}` 表示可剪位置，回信不标可剪词，不给附件或报酬。
- 先判断字面要求，再解析事实、拼回信、评星。配方满足字面条件才有一至三星，所有星级拿本单同额报酬。
- 发货后只展示本次直接后果；确认才保存人物变化与星级，重置回本单首次投料前。延迟信不提前剧透，也不修改已确认星级。
- 评分来自本人能知道的事实。三星不等于帮助警方，也不等于道德正确。
- `N01`、`M01`、`G01` 等是文案工作编号；普通订单已固定 `npc_luca` / `npc_nora`、`letter_n01` / `letter_n02`；`word_*` 为正式词 ID。主线与后续人物尚未进入配置，之后不随意改名。
- 保留 `letter_pa_01`、既有可剪位置和 A～G 回归预期。卢卡排除规则与两封普通来信修订后，内容版本递增为 `story-v0.3-r2`；技术扩展夹具仍不属于正式剧情。

## 从草稿到配置

| 草稿内容 | 配置落点 / 交接要求 |
|---|---|
| 人物与私人记忆对象 | `npcs.lua` / `ordinary_orders.lua`；字段与初态明确，遗忘只作用于本单指定对象 |
| 自我介绍、正文、地址、可剪位置 | `letters.lua` / `ordinary_orders.lua`；按[填写说明](../../scripts/data/填写说明.md)生成 `body:N`，正式存档后改位置必须升版本 |
| 词条 | 优先复用少量底层药效；显示词从人物生活中选择，避免反复剪相同的情绪词；新词的分类、药效与主词时间属性完整交付 |
| 字面要求 | `tags` 与已有 `duration/onset/workReady/residualAt/forbiddenEffect`；新条件先列需求 |
| 事件事实、回信与评分 | `followup.lua` / `ordinary_orders.lua`；重要事实有片段覆盖，组合覆盖单效果，不输出矛盾回信 |
| 药效与时间 | 全部正式主词 profile 已配置；B3/B4 合成、字面条件、事实、回信与评分已随 `bd606db` 拉入；B5 完整事务与 UI 尚待联调 |
| 成对互斥、官方行动、延迟信 | 尚需主线阶段接口；节点表是需求输入，不能硬塞入阶段 1 校验 |

两单现改为八个不同的新词：面包、答应、抬头、手稳；回家、笑、汤、等。此前重复剪勇敢、安静、累等的版本已撤下。大多数新词复用已有药效，手稳另提身体作用；30 个词已定义，三封正式可剪信提供 14 种词；其余待投放。不能据词库数量宣称身份结局已经可达，完整日程与运行仍需联调。

## 本批审稿重点

检查三件事：前置线索是否足以解释后果；每个星级是否有本人反馈依据；剧情状态是否只在确认后进入当前分支。主线表附了归案、逃脱与未解的纸面路线，属于写作走查，不能代替实际玩法验收。

下一批依据已审节点逐封扩写主线订单、附件与关键后续，再交五篇身份结局及四类案件短尾声。后续审稿意见直接记录在各文件修订记录中，不复制另一套规则。
