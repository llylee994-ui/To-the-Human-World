## 写作约定

- **信件形态（2026-10-03 世界观修正）**：铺子在人间之外，人间不知道它的存在；信不是写给店主的，是人物**念头**自己汇聚成的文字（像日记），被玩家打捞。每封按“自我介绍（本人腔调）→ 正文 → 落款姓名＋地址”三段写，不出现对店主的称呼、请求与投递说明。细则见[文风基准与润色计划 §0](文风基准与润色计划_v01.md)；现有全部信件按新框架待重写。
- 来信写人物的处境、愿望与生活，回信写做了什么、别人如何回应；减少解释游戏规则的文字。精确时限与禁用药效集中写在玩家可见要求栏，阈值、槽位、确认／重置等放交接说明，不在人物信里重复讲解。
- 药效边界保留在词条／效果定义与作者说明里。正文用行动和场景表达，避免反复解释“没有真的变出东西”；保留推知后果所需的线索和人物误解，轻松、夸张的后续仍须与事实相容。
- 玩家留在魔药铺。调查信息来自漂流瓶、回信和附件；不新增主动询问 NPC 的功能。
- 固定真凶是克莱拉；新分支改变信息与人物行动，不能改写案发事实。
- 维尔家族直接抢地与埃德蒙成年参与是固定过去；克莱拉的截信和谋杀不能替他们承担土地责任。“上帝惩罚”是老石匠的言论，不是叙述者认定的真相或谋杀证据。
- 玛拉与老石匠可以核对材料、执行有限返还，同时保留爱、愤怒与不原谅。受害家庭各自决定是否接受款项；不以三星、慈善声誉或抓到真凶代替赔偿。
- 普通正式订单包含自我介绍、来信正文、详细地址。`{{词}}` 表示可剪位置，回信不标可剪词，不给附件或报酬。
- 先判断字面要求，再解析事实、拼回信、评星。配方满足字面条件才有一至三星，所有星级拿本单同额报酬。
- 发货后只展示本次直接后果；确认才保存人物变化与星级，重置回本单首次投料前。延迟信不提前剧透，也不修改已确认星级。
- 评分来自本人能知道的事实。三星不等于帮助警方，也不等于道德正确。
- `N01`、`M01`、`G01` 等是文案工作编号；普通订单已固定 `npc_luca` / `npc_nora`、`letter_n01` / `letter_n02`；`word_*` 为正式词 ID。主线与后续人物尚未进入配置，之后不随意改名。
- 保留 `letter_pa_01`、既有可剪位置和 A～G 回归预期。卢卡排除规则与两封普通来信修订后，内容版本递增为 `story-v0.3-r2`；技术扩展夹具仍不属于正式剧情。

## 从草稿到配置

|---|---|
| 人物与私人记忆对象 | `npcs.lua` / `ordinary_orders.lua`；字段与初态明确，遗忘只作用于本单指定对象 |
| 自我介绍、正文、地址、可剪位置 | `letters.lua` / `ordinary_orders.lua`；按[填写说明](../../scripts/data/填写说明.md)生成 `body:N`，正式存档后改位置必须升版本 |

| 字面要求 | `tags` 与已有 `duration/onset/workReady/residualAt/forbiddenEffect`；新条件先列需求 |
| 事件事实、回信与评分 | `followup.lua` / `ordinary_orders.lua`；重要事实有片段覆盖，组合覆盖单效果，不输出矛盾回信 |
