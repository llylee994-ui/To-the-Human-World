## 1. 本轮叙事结构

前半段让玩家先遇见需要帮助的人，再发现同一死亡事件有五种说法；中段逐步看出被修改的地址与被扣下的举报；后半段连续出现三组成对瓶子，让玩家的魔药影响证人、档案和警方行动。

玩家始终留在魔药铺。表中的「警方取证」「递交账本」由人间人物完成，再通过信件或附件反馈。没有主动调查信，也没有最后点击凶手姓名的菜单。

真凶始终是克莱拉。药酒在案发当天下午被调换，夜间服用后延迟发作；死亡前七天的既有时间线不随分支改变。涉及毒性的正文只写架空征象，不写真实药物或剂量。

第2～9天 M01～M08，G01窗口第10～11天、G02第12天、G03第13天，经营至第18天收尾。前置延迟不顺延已过的渡船窗口；同日可出现多封信，无新增每日接单上限。旅行票第6～11天主动离场独立存在。

新增土地补线利用前中期附件和收尾窗口，不顺延固定船期、不削减普通订单；第18天只交代真实进展，不强制全部赔清。新增 L01 的一次性词卡、物料、金币另补账，不沿用30单模型的已通过结论。

下表「勇气／镇静」指药效轴，实际剪词以正文为准：M03、G02A、G03B主抬头，M04主等，安全／交接辅助等可在对应信中取得。沿用30词池，没有新增“见闻、收据、守门、封存”词定义。

- `M`：独立主线节点；`G`：成对瓶子组；`C`：案件结果；`I`：身份演出。
- 「玩家知道」只引用已经抵达的来信和附件，不把编剧知道的真相写进提示。
- 信息节点没有订单、药锅、报酬或星级；订单节点包含自我介绍、正文、详细地址与完整要求。
- 每个订单都需单独写三星路径；表中写作锚点不代替正式评分规则。
- 前置以当前分支的确认结果为准。建议日期是排期窗口，不允许跳过尚未发生的剧情因果。

### G01A｜托马斯：勇敢不等于准备好

字面主轴是 brave；明确提出在当晚发挥作用，不要求玩家保证破案。

- 勇气达标，calm < 0.6，forget < 0.6：他独自去对质，被赶走，躲到暂时无法联系的地方。已经说出口让他短暂满足，但害怕朋友受连累，直接评价写二星；不是死亡惩罚。后续是否救回证言按状态处理。

### G01B｜吕西安：镇定也能保护谎话

字面主轴是 calm；他要在稽查当晚保持镇定。

- 适量镇静且没有会妨碍本场景的额外效果：他稳住工人、阻止少年在门口说话，自认为避免混乱，可给三星。警方少一份仓库口供，收条与库存数字并不被抹掉。
- 额外勇气使他越过原计划，当众威胁少年；附近工人后来愿意为威胁行为作证。不能据「威胁证人」直接宣布他杀了埃德蒙。

### G02A｜阿德琳：递交不是把所有人交出去

字面主轴是 brave；本单的私人遗忘对象是她改账时使用的匿名代号对应关系，不是所有专业知识。

- 勇气 + 适量镇静、未遗忘：她保留原账，把资金去向与可识别病人的页分开说明，同时递交旧举报的收件 / 退件原始登记。本人满意，可写三星；警方得到原件比对渠道。
- 只有勇气：她一口气交出全部资料，警方追查诊疗所。原账仍有效，但匿名病人承担新风险。本人在直接后续得知有人被带走后，评价应体现她的遗憾，不能用不可知的未来灾祸扣星。
- 勇气 + 遗忘：她敢出门，却解释不清匿名代号；原纸没有凭空消失，但警方暂不能核对部分去向。本人发现无法说明，可写低星并留下进一步说明的可能。

未选克莱拉的短信按registerHeld选择：原件已转交则不能远程删除；阿德琳迟缓未取出时，仍留在封存柜中，不输出“已经交出”。

### G02B｜克莱拉：所有东西都有它的位置

字面主轴是 calm；她没有向玩家承认谋杀，也没有明说要毁证。

- 镇静且记忆完整：她按惯常流程剔除旧退件，把可见目录整理得井然有序，并安排离开灰港的行程。她在直接回信中满意地写「没人再为错地方的信争吵」，可给三星；信息缺口是案件代价。
- 镇静 + 遗忘：只淡化本单声明的那次旧举报处理记忆。她无法准确归回对应编号，留下可与 M07 抄页核对的错位。药酒配送副联仍在，但该错位本身只能提供追查方向，不能凭空生成谋杀证据。
- 镇静 + 勇气：她更敢于坚持自己的筛选正当性，可能主动解释原本回避的编号。解释与附件矛盾时形成可观察矛盾，不以玩家读心取证。

未选阿德琳不会自行把原账送出来；在封存前继续担心病人暴露。之后可以收到她的短信息回信，但不能把未完成的订单算收入或三星。

### G03A｜罗文：心平气和地犯错，也仍是错

字面主轴是 calm；他知道自己容易被人催着提前结束复核。此时再加遗忘，仅影响本单明确提到的「早先仓促判断的记忆」，不删除已存案卷。

- 适量镇静、记忆完整：他逐条复核已提交证词、药酒副联与旧信原件。证据完整时识别并拦住克莱拉；只有港口罪证时不能把吕西安的其他罪当成谋杀证明。
- 镇静但所需证据缺失：他可以满意于终于完成有序听证、给三星，同时报告谋杀案仍无法结论。没有证据时不为三星路线强行抓到真凶。
- 镇静 + 遗忘：他不记得自己此前为何对某个口供存疑，可能重复先前的错误判断。是否错抓由既有偏向和反证状态共同决定，而不是遗忘自动指定某人。

直接后续只写本轮听证、部署及已发生的行动；若渡船是否被拦尚未确定，正式确认后才触发 G03 的结果短信。

### G03B｜玛拉：离开并不表示原谅

字面主轴是 brave。勇气使她带着属于自己的土地文件离开宅邸；适量镇静让她把门口交接写清，遗忘只涉及前期已明确的父女争吵，不改变文件内容。

- 勇气、愿意留下交接、记忆完整：她去暂住处并寄出地址，可以满意、给三星。若警方此前已经正式安排拦截，克莱拉不能因此自动逃脱。正常交接仍可能遇到独立失守：旧班16:50撤、新班17:30来，玛拉17:00离开；克莱拉已备行李时步行8分钟到港，赶得上17:15登船截止和17:20离港。迟缓未离开则不开放该窗口。
- 勇气但冲动离开、交接缺失：出口短暂无人看守；只有克莱拉已经准备离开、且警方没有有效拦截时，窗口才促成逃脱。
- 遗忘争吵：她仍能离开，口述父女最后一次见面却不可靠。药酒副联与其他时间证据优先，不能为了反转把已经核实的事实重写。

未选罗文维持此前判断与部署，不免费生成最终问询、港口封控或谋杀拘捕。本版正式错抓由G03A草率命令及既有偏向／反证条件共同产生，以状态契约为准。
