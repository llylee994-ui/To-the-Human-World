## 两份愿望如何互斥

每个二选一节点有两份真实愿望，玩家只能实现一份。另一份立即装瓶丢回海里，在当前时间线永久关闭：不会再被捞到，没有延迟处理入口，不会寄回信，也不能换个标题补做。即使选中方药效不佳，未选方也不重新开放。

人物不因瓶子丢弃而消失，仍会参加日常工作或作最低限度的应答；这些行为不能偷偷兑现未选愿望。另一人物提供独立证据可以推动案件，但不代表原来的作证愿望得到实现。相同人物后来提出的新愿望必须由新事件引出，目标、时间及后果明确不同。例如第12轮“公示张贴前更正名目”和第16轮“新开具的本人收据写作返还旧债”不是同一个任务；后者成功仍保留前者错误张贴的公开伤害。

编辑器保留两份候选给作者核对，出口标明实现A/丢弃B或实现B/丢弃A。“未选愿望的后果”仅供作者，不当成被丢弃人物的回信直接展示。玩家后来只从本路线实际收到的信、附件和亲见中知道后果。

## 梗概框架

**前情 → 两个人的处境与愿望 → 选择前快照 → 实现一份、丢弃另一份 → 选中药效结果＋未选缺口 → 隔日普通愿望 → 新的主线节点。**

主线与普通愿望仍逐日交替，当前暂排18轮主线/36天。第9～17轮已有31个不同路线场景，每条实际路线只遇到其中适用的一场。每个场景均有两份愿望及分别不帮助的具体后果。不是31次连续游戏回合，也不是所有节点都要玩家经历。

| 阶段 | 实现一方的方向 | 另一方的缺口与后续 |
|---|---|---|
| 第9轮：仓库门口 | 帮托马斯递交见闻，或帮吕西安稳住核查 | 选少年后商人不能免费稳住仓库；选商人后少年原作证愿望关闭，不再补捞。 |
| 第10輪：少年已获帮助 | 新的归家、联络住处、工友旁证或额外保护 | 新任务也互斥；原纸、已有证词、指定遗忘分别保留。 |
| 第10轮：商人已获帮助 | 工友的现场记录/旧簿，或乔纳的独立副联 | 托马斯不再作为补救候选，工友也不能代他说未亲见的跑腿经过。 |
| 第11轮：分路 | 土地会面、寻找与送达、或独立配送原簿 | 商人路线进入独立来源，不能绕到少年安全证词；实际收到什么才记什么。 |
| 第12轮：关系与来源 | 公示与家庭答复、少年归家与额外核对、管事亲见与财务分类、原簿与具名说明 | 原纸不等于亲见，正常问询不等于额外复核，错误公示不被后来本人收据抹掉。 |
| 第13～14轮：患者与封存 | 接续治疗或转款说明；原件对读或秘书旧件交接 | 未选方的资料或保护缺口继续存在；既有暴露和永久记忆缺口不重置。 |
| 第15轮：问询与搬居 | 罗文真实复核和值守，或玛拉的同城搬居交接 | 罗文未获帮助不能免费部署；玛拉未获帮助不能自动完成搬居。案件仍依据真实材料、执行和登船形成四类结果。 |
| 第16轮：返还 | 本人收据名目、实际支付，或尚缺的住户来源/本人授权 | 名目正确不生出新付款，付款不要求当事人原谅；未支付的旧债仍欠着。 |
| 第17轮：物资 | 冬衣，或煤药及真实接诊地址 | 同期一辆车只跑一处，另一份愿望关闭；未确认的未来车次不补成成功。 |
| 第18轮：回信 | 汇集本支实际案件、返还、救助与身份结局 | 不补寄未选瓶的回信，不宣布没有来源的成果。 |

## 两处具体改动

### 被丢弃的少年愿望

第9轮选择吕西安的三种药效结果分别进入入口受阻或商人口述含糊场景。第10轮改为工友与乔纳，两份独立纸件各有自己的困难；全部出口进入第11轮独立文书路线。原来“选商人→下一轮帮少年安全作证→直接土地会面”的补做路线删除。

第9轮已经选择少年、但药效导致躲藏的路线，可以因新的落脚与联络事件继续；这与“原愿望未被选择”不同。独立管事亲见与经手原页/具名说明仍能使没有少年证词的路线查明案件，不因一个被丢弃愿望必然封死所有结局。

寻找未成的第12轮也不重复工友的原威胁记录或少年的原落脚告知。候选改成接待室门房对昨日接待经过的签认，以及同伴向少年家人寄平安家书；前者只是新的接待旁证，后者只有平安消息，都不补出跑腿证词或现住址。

### 接待室与末班船

接待室的一组候选改成少年盼着结束等候跟工友回家、罗文希望留人完成额外箱号复核。普通笔录可以保存已知内容，但一方成功不免费完成另一方愿望。

克莱拉要领取具名交接回执，携出私人物件会依清单查验。她认为调查仍集中在运输缺额，希望照已公告行程离开，避免绕开交接引起额外怀疑。交接延误时她选择等回执；这是一项人物判断，不是玛拉有拘禁权，也不声称物理上无法离开。正文将来需要呈现这一动机及事先告知的船期。
