## 1. 连续二选一的含义

第9～17轮每轮出现当前路线里的两封念头。选帮助哪位，药效再决定那个人怎样行动。下一轮读取已经发生的结果，换成相关人物、场景和候选；不是每轮换一句回信后又回到完全相同的下一场。

同一时段出现两封念头不表示人间规定只能询问一个人。人物不知道魔药铺，玩家也不亲临人间；他们因同一项核查、约定、封存、接货产生自己的困难。未选方仍能做已经交代的日常行动，但不会免费获得额外勇气、完成签认、找到失联者或生成证词。帮助罗文时，少年仍可按正常问询回答；不需要把所有配角行动都解释为另一个订单已完成。

允许在后期汇合时间阶段，但必须带着原约、证词、暴露、行踪、付款与签收的实际差异进入。一个结局标题可以包含多条经历；不把未经条件筛选的箭头组合当成可玩路线数。

## 3. 人物与物件如何推动事件

- **老石匠**：第1轮以长期抗议出现，第2轮葬礼冲突留下旧图与联系住处。玛拉清点原约、寄邀请并收到答复，才进入实际会面。原约未齐则先清点，不能直接公示所有家庭已确认。
- **罗文与工友**：第8轮已说明教区接待室、地址和临时安顿职责。少年自己到场或由同伴陪同，再实际问询和收纸；找地址不等于作证。躲藏支路有实际安全问询补救。
- **宅邸管事**：第8轮的副联已有他的签收名字，第11轮沿实际副联找人，第12轮正式核实亲见。他看到撤旧签和另瓶交接，不知道瓶中内容，不越权宣布谋杀。
- **西蒙**：第7轮介绍文书室、原收件簿、摘录与封存职责；后期能对读实际保管的原簿。目录、抄页、见证摘录、原簿来源不能混为一谈。
- **克莱拉**：前期以具名归档通知、经手登记和其他人的亲见逐步出现；后期因封存通知办理目录。她的解释欲可留下自相矛盾的具名说明，却不能受魔药驱使突然招认杀人。
- **玛拉**：第15轮搬往同城北街姨母家，不是坐船永久离城。第16轮本人按约到文书室会馆办理返还；宅邸授权有缺口时本人补交，不由未选管事免费办完。
- **教区物资**：第1轮有寄存捐衣，第14轮两条路线均收到实际点收通知；第17轮的一小批煤药是另募的独立供给，不是自动追回失踪的二十四箱，也不挪用家产赔偿。借车本期只能跑一处，下一趟受路况影响尚未确定。

## 4. 问询输入与固定案情

克莱拉在案发当天下午调换药酒的固定真相不变。没有姓名指认菜单，案件结果由人物真实取得的材料、问询与执行产生。

完整问询来源需要：

1. 检验摘要、V17配送来源、改革稿及旧K42副本已抵达。
2. 原登记经实际对读核实，或克莱拉自己的具名经手说明已经取得。
3. 安全完整的少年证词，**或新增第12轮管事当面核实的独立亲见证词**。

第三项的替代是本稿新增设计：旧稿最后问询本就需要管事说明亲见，本稿将这次真实问询前移到独立文书路线。它不表示一张配送收条、威胁旁证或遗忘后的有限口述能代替可靠证词。少年永久记忆缺口仍保留。

第15轮还须真的召集经手人、复核供货留样与签收、对读撤签登记、追问矛盾并实际控制人，才形成归案。材料齐备不等于抓到人。原登记充分核对的常规账房路线还交付经跨港经办人核实的吕西安日间反证；取得后后续遗忘不能删除。错抓只在确有运输偏向、无已核实反证且实际发出错误谋杀拘捕令时成立。

## 7. 代表路线核对

以下是作者抽样核对，固定四类案件结果并不代表只有这几条完整经历。节点间带条件的连线由作者核对，编辑器不会执行游戏状态机。

| 路线 | 关键经历与结果 |
|---|---|
| 安全少年＋原登记 | 仓库安全递证→保护/联络→土地会面→匿名核对→实际原登记→罗文完成问询和控制→归案。 |
| 安全少年＋具名说明 | 可靠少年证词保留→克莱拉为解释流程留字据→罗文实际对读→归案；不是只能连续选A。 |
| 躲藏后补救 | 躲藏→同伴陪同实际到接待室并问询；或寻找送达→下轮正式问询→可靠证词→后续材料与执行→归案。 |
| 门外少年补救 | 商人关门→下一轮少年到安全问询地点递纸→恢复调查推进；没有恢复不存在的失忆。 |
| 商人记忆受损 | 商人调货含糊→“收货簿旁的少年”→帮助仍记得见闻的少年→安全作证；不能进入少年失忆场。 |
| 少年记忆受损＋独立来源 | 永久号码缺口→副联/原簿→实际找到管事，核实亲见→原页/具名说明→真实问询与拘捕→归案。少年的记忆没有恢复。 |
| 离港 | 证词或经手材料不足→秘书已形成并告知出行计划→玛拉办妥交接→无实际封控且按时登船→离港。 |
| 错抓 | 没有可靠少年/管事证词且无反证→运输线索偏向→罗文漏核药酒、实际错误拘捕吕西安→错抓；不是运输案正常拘留。 |
| 守港但未解 | 缺可靠来源，罗文安排真实值守但不强行定罪→案件未解；后续土地或救助仍可有进展。 |
| 材料齐备但未执行 | 已有完整来源，罗文迟迟没完成召集→未解；不因材料数量触发归案。 |
| 土地尚缺 | 先查少年或独立经手资料，未完成土地会面→会馆补原约、本人意愿或预备款→未实际支付不写到账。 |
| 患者迁散 | 先前暴露/转诊失接，未收到接续回执→“两处接诊的地址”→先确认实际接诊与在院者才签收；既有暴露不撤销。 |
