## 1. 当前实际有什么

历史基线只有 8 个正式词：睡觉、梦、安静、快乐、勇敢、忘记、累、饿，以及首单人物埃利亚斯·沃德；其妹妹与母亲是家庭资料，不是独立订单 NPC。技术扩展夹具的灯匠、灯和守夜不计正式剧情内容。

目前全部 30 词、22 标签、6 个主词时间表已配置；正式 NPC 有埃利亚斯、卢卡、诺拉，三封可剪订单提供 14 种词，其余 16 种待后续信件投放。B3/B4 已随 `bd606db` 拉入，完整事务、主线与身份仍待联调。主线有九位具名人物的角色设定，不能把「有角色档案」写成「九人的订单已实现」。

| 用户关心的状态 | 当前正式定义与来源 | 后续写作方向 |
|---|---|---|
| 喜 | 快乐 / 笑 → happy；首单 / N02 有来源 | 欢喜、期待自然出现在来信，不必全部另造同义词条 |
| 怒 | 生气 → anger；定义已配置，词源待写 | 抗争、冲突或越界，不预设为坏效果 |
| 哀 | 难过 → sadness；定义已配置，词源待写 | 哀悼和哭出来，不把所有愿望写成抹除悲伤 |
| 乐 | 快乐 / 笑 → happy；首单 / N02 有来源 | 吃饭、玩耍、节庆，后果依情境区分 |
| 茫然 | 茫然 → confusion；定义已配置，词源待写 | 难以整理注意，与遗忘分别写场景 |
| 理性 | 理性 → reason；定义已配置，词源待写 | 核对已有信息与权衡，不凭空获知真相 |
| 放松 | 放松 → relax；定义已配置，词源待写 | 缓解紧绷、降低警觉，与睡眠和强镇静分开 |

这三项区别不能靠换词掩盖：理性不是镇静；放松不是困倦；茫然不是遗忘。已有 calm 描述含「压低行动欲望」，不足以完整承担它们。

## 2. 首版 30 词池

沿用开发计划 24～30 个词的数量基线，先把语义补齐，不因扩写直接增加到上百词。下面恰为 30 个不同词，现均有定义与主词 profile；部分出现来源和组合覆盖仍待后续订单。

| 状态 | 词条 | 数量 |
|---|---|---|
| 原有定义：6 词有首单来源，勇敢 / 饿待投放 | 睡觉、梦、安静、快乐、勇敢、忘记、累、饿 | 8 |
| 正式定义与 N01 / N02 来源已配置 | 面包、答应、抬头、手稳、回家、笑、汤、等 | 8 |
| 正式定义已配置，全部待交付信件来源 | 生气、难过、茫然、理性、放松、害怕、安心、想念、信任、怀疑、嫉妒、好奇、疼、温暖 | 14 |

生活词与直接情绪词同时保留。用户提出的生气、难过、茫然、理性、放松都可以直接剪，不强制把它们藏在比喻中；另一方面，不要求每封信都罗列一整套情绪。

类别本批统一为八类。既有分类实际覆盖身体、情绪、记忆、睡眠；新稿另提行为、关系、物件、时间，合计可能达到 8 类，超过开发计划原先 5～6 类的预估。这里明确登记差异：暂不重分类旧词、不修改无名者口径；本批已同步开发计划为 30 词 / 8 类，不能悄悄给同一词多挂类别补身份门槛。

## 3. 药效与人物态度

以下保留语义和后果方向；词与药效定义均已配置。信任、怀疑、嫉妒等对象性订单仍须交完整条件与后果，不能把词定义当成世界状态系统已经接入。

| 正式词 | 需要表达的作用 | 可能的好结果 / 代价 | 内容约束 |
|---|---|---|---|
| 生气 | 增强愤怒，倾向表达不满或追究 | 工人敢于讨薪；也可能把不相关的人当出气对象 | anger 已配置，N01 有片段；正式词源待写，行为按场景配置 |
| 难过 | 加深悲伤、允许失落被感知 | 为逝者哭出来、停止装作无事；也可能难以继续手上的工作 | sadness 已配置，N02 有片段；正式词源待写 |
| 茫然 | 思绪难以组织、行动判断暂时不明确 | 暂停过于仓促的决定；也可能错过接待或工作 | confusion 已配置，N01 有片段；词源待写，不写永久失智 |
| 理性 | 增强核对、权衡和保持思路的能力 | 找出已有账目矛盾；也可能把关系只看成收益与风险 | reason 已配置；只处理本人已有信息，不凭空生成凶案知识 |
| 放松 | 缓解身心紧绷、降低警觉压力 | 能继续做事而不紧绷；也可能忽略需要保持戒备的场景 | relax 已配置；与 calm 行动迟缓及 sleep 分开，词源待写 |
| 害怕 / 安心 | 对特定风险的感受增强 / 减弱 | 更谨慎 / 愿意迈出一步；也可能退缩 / 误信危险 | fear / safety 已配置；正式词源与风险场景仍需完整订单 |
| 信任 / 怀疑 | 对已声明对象的信任倾向 | 愿意听 / 认真核对；也可能被骗 / 误伤关系 | 对象必须写明；不对所有人、所有证据全局生效 |
| 想念 | 已有关系或记忆更容易被唤起 | 愿意联系亲人；也可能难以放下 | recall / dream 已配置；订单需声明记忆对象，词源待写 |
| 嫉妒 / 好奇 | 关注比较或未知之事 | 努力争取 / 愿意了解；也可能争抢 / 越过隐私边界 | envy / curiosity 已配置；嫉妒对象与词源待交，好奇已有趣味片段 |
| 疼 / 温暖 | 身体痛感 / 冷暖体验 | 感觉到身体异常 / 能度过寒冷；也有加重不适或错判环境的可能 | pain / warmth 已配置；词源待写，不自动当治疗或免疫 |

当前定义以 words.lua / effects.lua 为准，不再请求重新发明标签。下一批优先交生气、难过、茫然、理性、放松的完整词源订单；新记忆对象、世界条件与未支持接口仍先交字段表。八位后续 NPC 是写作候选，不能按 30 词定义已落盘便勾成已交付订单。

喜与哀、放松与理性可以同在，不默认互相抵消。由人物和场景解释，例如母亲见到儿子很高兴，却仍想念亡夫；镇静的商人依然能做坏事；理性的证人也可能害怕。不能为每个人固定「怒就打一星，乐就打三星」。

## 4. 时代口径

现有大纲是「架空中世纪 / 近代早期欧洲沿海城镇」，没有绑定真实年份。建议保持这个混合定位：港口、石街、教堂、行会、城镇警备、领地与商人财富共同构成灰港；不突然切换成现代都市或严格历史复原。

文案用钱袋、收条、木工、借据、铺面、集市、船期等生活信息表达制度。已有「救助会财务主管」「地下诊疗所」属于架空组织，沿用角色功能，信件语言尽量避免现代项目汇报口气。玩家仍不进入外出地图。

埃德蒙是商人出身，玛拉是商人家庭继承人；不能因为富裕就把他们算作世袭贵族。贫穷也不等于农户：码头工、城市帮工、佃农、外来短工有不同的生活限制。

## 7. 写作检查标准

- 同一药效至少让两个处境不同的人表现出不同后果，但不靠任意换规则制造反转。
- 每位独立订单人物有姓名、年龄段、职业、生计、家庭 / 关系、住处、识字情况与本人愿望；儿童或不识字者要有合理代笔来源。
- 不让成年男性只谈工作、女性只谈感情、儿童只提供线索、老人只谈死亡。富人也有小愿望，穷人也可以嫉妒、幽默、主动选择。
- 普通订单至少有一条完整三星路径；同一三星结果可以对他人不利。情绪类别不自动决定评价。
- 全词池按确认后可得来源排表：早期基础、主线与普通订单、互斥组所选路线、终局留存。账面 30 词不等于任一路线都能拿到 30 种。
- 新词涉及作用、对象或时间时，先交定义和完整后果，再接配置；不改首单旧位置、存档版本或合成算法来绕过联调。

本批只建立覆盖与优先顺序，不把八位候选写成八个已交付订单包。下一步优先扩写贝娅的生气、马丁的放松与雅各布的茫然，结合已有人物补理性和哀悼的普通订单；这样同时检验语义、阶层和实际玩法，而非先空造一大张词表。

上述词条的标签与主词属性已定义，具体值以配置交接表为准。八位 NPC 仍是候选，不能计作八份已完成的订单；正文交付优先补真实词源与生活场景，避免靠扩充定义假装增加了可玩内容。
