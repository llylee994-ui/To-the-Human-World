# 供给验算表 v01（N01–N10）

> 2026-10-08 · 数值层第三张表。用途：确认"一次性、可攒用"前提下，**每单主轴与每支主导键都到得了**，并核对 22 属性覆盖。本表为骨架＋N10 试算；路径以最终[词条数值表](词条数值表_v01.md)的剪词位置为准。

## 1. 口径

- 词条一次性；剪下后想什么时候用就什么时候用（可留后）。
- 每单主轴 ≥2 条来源路径（本信一张＋先前一张）；每支主导键 ≥2 条路径。
- 来源按投放日核（"最早 D 日"取[逐日投放与经济验算](逐日投放与经济验算_v01.md)现有表）。
- 到不了的对象记入**漏单清单**，回文本补位或调整键位。
