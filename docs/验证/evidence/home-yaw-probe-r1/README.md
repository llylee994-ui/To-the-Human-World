## 查看与操作

- 打开本目录 `native-review.html`，可查看 Maker 原生窗口的带时间连续截帧。它只回看截图，不运行游戏，也不是浏览器重新渲染的示意动画。
- 原生手动复查：在 `scripts/ui/landscape/DevChecks.lua` 中只将 `yawProbe` 改为 `true`，保持 `yawProbeAuto=false`。通过 Maker 官方流程刷新**仍存活**的预览；已停止的预览需另获启动授权。本轮交付和最后刷新均恢复为两个开关 `false`。
- 主页顶部点击「转头验证」→ 出现蓝色前墙、右侧桌面与固定屏幕按钮。
- 点击「播放」→ 1.2 秒内向右转头，橙色右墙进入正面，药炉到中央；镜头不靠近、绕行或横移。连点播放不重启；完成后再点可从原朝向重播。
- 点击「复位」→ 恢复前方。播放中也能复位。
- 点击「关闭」→ 回原主页。重新打开应仍是起始视角。关闭在下一次 Update 执行，避免当前 pointer-up 穿透。
- 窗口可用尺寸变化、最小化或大于 0.25 秒的更新间隔会复位播放；仅切走焦点但引擎仍正常更新时允许继续，方便后台取证。没有导航或业务完成回调。
- 复查后把 `yawProbe=false`，只刷新存活预览。本任务没有启动原本停止的预览或操纵 OS 鼠标。

## 参数与实现

| 项目 | 本轮默认值 |
|---|---|
| 坐标系 | Y 向上，+Z 前方，+X 右方，米 |
| 相机世界位置 | (0, 1.65, 0)，固定 |
| 药炉中心 | (3.2, 1.15, 2.8)，固定 |
| yaw | 0° → atan2(3.2, 2.8) = 48.814075° |
| pitch / roll | 向下 8° / 0°，固定 |
| 垂直 FOV / aspect | 50° / 16:9，固定 |
| 时长、缓动 | 1.2 秒；smoothstep `t²(3−2t)`，无回弹 |
| 纹理适配 | 16:9 等比放入验证区，整数 16×9 倍数，最大 1600×900 |
| 资源 | 独立 Scene/Camera/Viewport，48 个固定内置几何物件，纯色材质 |

相机和对象只在建场景时设置位置；每帧只赋相机 Quaternion 的 yaw，调用 RenderSurface.QueueUpdate。UI 树不随帧重建。纹理句柄用 nvgDeleteVideo 释放，解绑 RenderSurface 后释放纹理；独立 Scene 和自建材质关闭时释放，不释放共享缓存资源。真实场景已关闭重开，未做 GPU 内存分析。
