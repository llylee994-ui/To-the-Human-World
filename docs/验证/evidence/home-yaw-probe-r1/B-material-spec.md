# 给 B 的最小素材规格（建议，尚未制作）

成果：C-HOME-YAW-PROBE-20261012-r1-v01。由用户转交 B；本轮没有生成、修改或装载正式美术。

## 已证实与未证实

Maker 已运行独立场景、固定位置透视相机、单独渲染目标及 UI 纹理显示；只变 yaw 能使墙格和桌沿产生正确的透视变化。几何体用的是纯色材质。

正式方案建议沿用这条相机/UI 链路，以**同一个观察点的局部立方全景**表示静态房间。它是方向投影，不是把宽图贴到一张平面上平移。固定站位只转头不需要位移视差；本轮没有验证全景贴图的 UV、接缝、过滤或与现有主页首帧的重合，不能把此建议写成已完成的美术方案。

## 必需

1. **先校准现有主页**：以 project 201 / home 189 的实际合成为起始画面，统一观察点、地平线、镜头 FOV 和桌沿消失点。不得改变主页家具布局。若现有插画的透视不能同时符合单一镜头，须先交误差叠图供用户选择小范围修画；不能默默替换主页。
2. **同机位的两个方向面**：前向 `+Z`、右向 `+X`，均为 90°×90°透视投影的正方形 PNG，建议每面 2048×2048，RGB/sRGB、无 UI/文字。不是两个独立生成的普通页面。前向面图像右边必须接右向面的左边；两面上方均为 `+Y`。前向面横向是 `+X`，右向面横向是 `-Z`。须附一份包含观察点、朝向、FOV、面顺序、上下方向的说明。
3. **补全右侧缺失内容**：原画右边以外的墙面、层架与侧面、桌面延伸和边缘、转头后可见的药炉周边；同一机位中原图已遮住且将进入视线的区域也要完整。不能扩大旧右侧裁切、拉伸原图或复制药炉填空。
4. **同一空间的配准小样**：先交起始／中间／结束三张 1920×1080 的透视预览，全部从同一投影母版或同一固定机位导出；同时交母版。三张预览只是检查材料，不能代替投影母版。首帧必须与现有主页叠合检查桌沿、门框、层架、药炉等定位点，照明、笔触和遮挡连续。

两个方向面覆盖水平约 `−45°…135°`，足够包住本探针 `0°…48.814°` 的转向及约 79.3° 的水平视野；固定俯仰向下 8°、垂直 FOV 50°。这是**探针包络与试制规格**，不是正式主页被批准的角度。正式药炉已在主页画面内，正式结束 yaw 应根据首帧校准后药炉的方向求出，不能照搬占位空间的 48.814°。如果校准后的上下或水平视域超过这两个面，再明确追加所缺方向面，不先要求整间房全部 3D 化。

## 哪些现有素材可以复用

- `assets/image/home-entry-r3/` 中的背景和现有物件可继续用于原主页；也可作为全景首帧的颜色、笔触、构图和纹理来源。
- 固定机位下，已有图中观察到的物件表面不会因只转头而凭空换成另一面。已知视域内的像素可经正确的透视投影映射复用；**不能直接作为屏幕贴片平移/转动**。
- 原图视域外的内容没有像素依据，必须补绘。已交的炼药近景若站位、透视不同，只能作为风格和物件参考，不能接到主页旁边声称连续。
- 金币、天数、按钮等界面层保持屏幕空间独立。后续要活动的船、烟雾或交互层，须另做同投影关联；本轮没有接入。

## 可选

- 每面 4096×4096 母版，运行时下采样；先用 2048 小样验配准和接缝，避免无效精修。
- 同观察点完整六面立方图，供以后更大范围转头；本轮只向右，不必预先制作。
- 分离活动物件、静态环境和遮挡蒙版，附相同投影参数；后续有动画需求再做。
