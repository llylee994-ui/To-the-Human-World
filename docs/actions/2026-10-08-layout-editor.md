# 自用网页排版编辑器 v0.1

## 状态与背景

- 状态：Completed（实现与本机自检完成，待 A 审查和用户体验）。2026-10-08，C 执行；依据用户本轮明确开发授权，无 A 任务编号。成果版本 v0.1.0。
- 基线：fengyycon@207f5c6；保留已有草案、接口手册、原型与其他未提交变更。
- 范围：本机网页工具，多页面、共用图片库、画布操作、图层排序/隐藏/锁定/删除、撤销、自动保存、预览、完整导入导出和简单启动。
- 采用本机 Python 标准库服务 + SQLite 统一保存，浏览器窗口共用服务端状态。同页单写租约，不同页可独立编辑；页面版本和项目世代校验拒绝过期写入。此为本轮技术实现选择，可供 A 审查。
- 默认画布 1080×1920；素材/页面/实例独立稳定 ID。组内物件随整体变换，删除实例保留素材。撤销限本窗口当前页面的连续编辑会话，接管时清空旧历史。
- 完整 ZIP 含版本化 project.json 和原始图片。导入替换前自动备份，其他窗口编辑期间拒绝替换。
- 本轮不改 Lua、data、剧情、数值或正式美术；未调用图片生成。网页布局只提供后续 E 接入的数据，不宣称引擎已接入。

### 中间问题与修正

- 首次测试使用 Python 3.13 默认临时目录，Windows 沙箱 ACL 导致无法打开数据库；改用工作区下继承权限的隔离目录。此为测试环境问题，最终检查正常。
- npm 离线缓存与受限网络最初无法取得浏览器测试依赖，随后通过权限工具成功安装仅供测试的 Playwright。编辑器本身无需该依赖。错误缓存路径产生的两个 `%USERPROFILE%` 临时目录经边界核对后已清理。
- 加固租约续期后，3 个测试用例错误地沿用了另一页的令牌；调整测试构造后通过。真实网页切页已清空令牌。
- 启动隔离检查发现 Windows 第二进程读取锁定字节会直接抛错；改为检查文件大小后加锁，第二服务现在返回明确说明，原数据不受影响。
- 一次证据生成脚本在尚未打开预览框时选比例而超时；修正操作顺序，最终整套浏览器测试通过。
- 实现时修正组内隐藏/锁定切换的取值时机，并让拖动期间的待保存任务延后到松手后，避免保存中间拖动状态。

### 未执行与限制

- 未测试手机触控、Safari、跨计算机协同或 Maker/Lua 接入；本版定位为本机桌面制作工具。
- 同页单写，约 1.2 秒刷新，非同页同时共同编辑。切页或重新取得编辑权会清空本地撤销栈。
- 仅图片图层；动态文本、动画和游戏行为由后续接入承担。手机比例预览是居中裁切示意。
- 断线/冲突时的应急 JSON 只含单页布局，供恢复核对；正常“导出项目”ZIP 才包含完整原图与全部页面。
- 关闭服务后仍可重新启动恢复；交付时测试服务已退出，用户通过根目录启动脚本开启正式空项目。
