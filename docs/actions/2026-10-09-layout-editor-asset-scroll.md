# 排版编辑器素材库滚动修正

## 状态与背景

- 状态：Completed（修正及本机浏览器自检完成，待 A 审查与用户体验）；2026-10-09，C 执行。任务来源：用户截图反馈素材过多后展示不全，明确要求素材栏可上下滚动。成果版本：`asset-scroll-r1`，项目数据仍为 v0.1.0。
- 依据：编辑器 v0.1.0 与用户本轮截图（15 个素材）；沿用项目 AGENTS.md、project-control-report、action-document，并按 diagnosing-bugs 复现显示问题。
- 范围：左侧素材列表的高度分配、卡片显示与垂直滚动；保留上传、搜索和页面导航入口。
- 已确认：原有 `.asset-grid { overflow-y:auto }` 未能滚动，因为默认网格行高被压缩，卡片内部内容随之被裁切。改为按内容分配行高，列表在剩余空间内独立滚动。
- 保护用户当前项目、素材原图及其他窗口修改。本轮使用独立测试数据，不改正式数据库；不改游戏逻辑、美术、导出格式或多窗口协议。

## 实施措施

1. 在隔离的本机编辑器实例复现 15 个及更多素材时的卡片尺寸与滚动行为。
2. 按复现证据最小修正素材栏 CSS，使上传和搜索固定可见、素材卡片不被挤扁，并有明确的垂直滚动条。
3. 用真实浏览器验证滚轮、拖动滚动条、最后一项可点击、搜索，以及常见窗口尺寸。
4. 目视截图、检查改动范围，更新本行动记录与操作说明。

## 自验证结果

- 已复现原问题：隔离服务、真实 Chrome、15 个素材。1440×900 时卡片高 48.5，1024×768 时仅 32；后者名称底边超出卡片。两种窗口列表均 `scrollHeight == clientHeight`，滚轮后 `scrollTop == 0`。结果：FAIL。
- 原始复现证据：`scripts/layout-editor/.local/asset-scroll-before-1791530528450/`，含结果与两个窗口截图。
- 单变量浏览器对照：只注入 `.asset-grid { grid-auto-rows:max-content }`，卡片恢复为 118 / 103 像素，滚轮到达列表末尾。确认根因是默认网格行高随受限容器压缩，卡片自身 `overflow:hidden` 又裁掉内部内容；已有 `overflow-y:auto` 没有产生可滚动溢出。
- 对照证据：`scripts/layout-editor/.local/asset-scroll-before-1791530568718/`；只在隔离浏览器内注入样式，尚未修改生产 CSS。
- 最终验证命令：PowerShell 将内联 Node/Playwright 检查脚本通过标准输入交给 `node - after`；脚本调用既有 `Store.upload` 生成 40 个隔离测试素材并启动 `server.py --no-browser --port 0 --data-dir <独立目录>`。测试 Chrome 使用 `ignoreDefaultArgs: ['--hide-scrollbars']`，使检查包含真实可见滚动条。
- 1440×900、1024×768、800×600 三种窗口，各验证 15 个及 40 个素材：均 PASS。缩略图及名称未被挤扁；滚轮可下滚和回顶；鼠标拖动滚动条能到达底部；最后一张完整可见且点击加入画布后自动保存成功；上传、搜索位置不随列表滚动；页面没有外层纵向溢出。滚动条占宽 12 像素。
- 搜索筛选一个结果、无匹配结果通过；JavaScript 异常列表为空。
- 最终矩阵证据：`scripts/layout-editor/.local/asset-scroll-after-1791530670868/`，包含 `results.json`、`after-1440.png`、`after-1024.png`、`after-800.png`。已实际查看 1024 与 800 截图，确认素材滚动条、名称、上传与搜索均可见，画布和图层栏正常。
- 补充命令 `node - small`（内联检查脚本）：空素材库在 1440×900 与 800×600 的引导和上传可见；使用项目现有 BG04 两版及 H06 原图仅向隔离服务上传，1 至 3 张素材卡片保持完整高度，空提示正确隐藏；JavaScript 异常列表为空。证据：`scripts/layout-editor/.local/asset-scroll-small-1791530741948/`。
- 上述独立测试服务和无界面浏览器均已退出，未访问或修改用户正式项目数据库；素材原图仅作只读输入。
- `git diff --check` 通过；既有 `scripts/README.md` 仍提示 LF→CRLF，与本次修改无关。本次三个文件的逐行尾部空白检查通过，已生成最终网页源文件、截图及结果 JSON 的 SHA-256 清单 `manifest.json`。
- 未执行：Firefox、Safari、手机触控；未重跑存储/多窗口协议、游戏测试或 Maker 预览，本轮未改相关代码。初始两次证据为问题复现及单变量对照，不作为最终修正截图。
