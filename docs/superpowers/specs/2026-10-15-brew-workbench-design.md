# 炼药近景与投料交互设计

用户在本会话确认采用讨论建议并授权编写计划及开工。单人执行，不使用子代理。

## 交互

- 延续现有药锅推近过渡，落点仍是同一药铺工作桌；复用房间、锅、木纹、四种原料、词条托盘和记录书图片。
- 进入炼药，左右托盘和记录书同时展开，各自可收起及通过页签重新打开。记录书默认当前委托，原有故事书签可以浏览全部已收到故事。返回主页保留草稿；再进近景默认双栏展开。
- 四种非词条原料固定一排：海盐、夜露、灰烬草、干花瓣，显示名称及扣除已选份数后的可用量。点击显示实际配置说明及投入按钮；拖动取一份，瓶子本身保留。
- 词卡保留来源 tokenId。触摸纵向移动优先滚动，向锅口横向拖动进入拿起状态；鼠标越过阈值可直接拖动。点击纸条选中，提供等价投入按钮。
- 拖动仅改变显示，合法锅口松手才调用 PlayModel.Drop。失败或落在其它位置不改变草稿；保存成功才呈现投入反馈。槽内按钮取出，不能静默替换主辅词。拖动取消包括模态、导航、窗口变更、失焦、销毁；其它手指不接管当前拖动。
- 中央配方纸合并药槽与摘要：槽位读取实际设备；显示主词、辅词、原料数量、当前药效及必要条件。不展示未发现后续或预判星级。心愿取当前来信已强调的原句，没有映射时展示当前要求并可阅读原信。
- 熬制只提交一次。成功保存 pending 后播放约一秒翻涌烟雾，可跳过；结束打开已保存后续。条件不足留在配料；失败不播放成功演出。
- 后续模态正文可滚动，右上固定星形及“一/二/三星”，底部固定重新调配、确认发货。关闭保留 pending，按钮重开。历史详情只读，星级固定在阅读区上方。
- 动画中失焦/改尺寸/导航取消显示，不撤销已保存结果、不重新计算、不自动发货。恢复后可以从锅旁或 HUD 重开待处理结果。

## 边界

前端写 scripts/ui/landscape 及对应测试，复用同一个 GameSession 和 PlayModel；不修改 core、systems、data、数值、存档版本、素材源图或引擎库。UI.Scale.DEFAULT，坐标与指针均使用 UI 基准像素，不新建 NanoVG frame。沿用 HarborStyle 的字体、纸面及木纹。已有托盘/记录书独立入口继续使用。

## 用户补充：俯视托盘与无提示拖放（已接入代码，待画面验收）

以下为用户在斜俯视概念稿后的明确修订要求，优先于上文旧视觉描述。2026-10-16 已按确认方案接入代码；用户选择本轮不启动预览，因此不表示已完成实际窗口和手机验收。

- 原料托盘为完全俯视的长方形木托盘，四角方正、外框与三道木隔板清楚，四种原料横向各占一格；名称与数量留在原位置的静态标签上。
- 药锅沿用已认可的斜俯视近景方向，托盘不沿用上一稿的梯形透视和前立面。
- 拖动仅显示物品图像，不显示跟随指针的额外名称标签。词卡自身的卡面文字属于物品本体，不另叠物品名。
- 锅口投放判定范围适度外扩，始终不可见；移除锅口高亮、轮廓、填色及调试命中范围。范围不能覆盖邻近配方槽或侧栏。
- 合法松手且草稿保存成功后，演出约 0.3–0.45 秒滑向锅口、缩小落入的过渡，再出现短暂涟漪/小气泡；容器与原料库存位置保留。动画不重复提交草稿，不触发自动熬制。
- 无效松手回到原位置；保存失败不播放成功落料。失焦、切页和尺寸变化可取消临时动画，不撤销已保存草稿。
- 熬制仍需明确点击按钮；投料落入过渡与熬制后的烟雾为两个阶段。

## 验收

隔离真实业务检查：双栏独立关闭、无订单、来源卡、锅口/取消/保存失败/满槽、投料保留、默认当前故事、试做一次、跳过和中断不重复计算、固定星级与按钮、发货失败及重置历史；原主页、记录书与托盘回归。LSP 无新增 Error。每批修改后检查预览，存活则刷新并读日志/check；停止则不启动。当前预览存活，既有 DDS/themis 启动错误单独记录。实际窗口与手机检查分别报告。
