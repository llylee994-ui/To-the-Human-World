# 商队木柜台商店与共用原料素材

用户已选择木柜台近景方案。商店左侧陈列四种原料，右侧显示所选商品、真实价格、库存、今日余量及购买按钮；透明商品素材与炼药共用。

## 视觉与资源

- 延续药铺和海边的手绘木材、旧纸与黄铜色调。1920×1080 背景仅包含空柜台和船舱氛围，商品及文字由界面叠加。
- 四件独立 1024×1024 透明 PNG：海盐陶碗、夜露软木塞玻璃瓶、灰烬草麻绳草束、干花瓣亚麻袋。统一略俯视角、左上暖光、完整轮廓。无烘焙文字或价格。
- 用 Maker 图片工作流生成并保留原回执/映射。资源放 assets/image；前端映射文件不修改 data 配置。
- 商店商品格、详情大图与炼药原料行使用相同资源。未知原料保持文字可用，不伪造美术。

## 界面与交互

- 商店为屏蔽底层点击的独立全屏浮层，关闭返回原 home/seaside/brew 场景，不消费、不清投料、不改捕捞进度。
- 左侧两列商品，选择只改变显示状态。右侧旧纸详情显示名称、配置说明、价格、已有份数、今日余量与每次购买一份。
- 余额不足、售完、待处理锁定显示明确原因；购买通过现有 PlayModel.Buy，保存成功后刷新库存及余额，保存失败保留原状态并在店内显示提示。
- 当前只有四种原料，不新增设备、配方、特殊商品或经济规则。
- 小屏缩小商品图与间距，详情独立滚动；关闭、购买保留至少 44 UI 基准像素触摸尺寸。兼容现有安全区和平台胶囊避让。

## 实施边界

前端只修改 scripts/ui/landscape，新增资源映射与 ShopView；Panels 的炼药原料行复用贴图。main、PlayModel、core、systems、data 与玩家存档不改。保留工作区既有剧情/工具改动，不提交或远端构建。

## 验收

隔离真实业务检查选择不写存档、购买对应原料、余额/限购/保存失败、关闭原场景与草稿保留。运行主页/海边/HUD 相关回归及 Lua 诊断。检查每图 alpha 和资源尺寸并实际查看。每批代码/资源后查询官方 preview status，仅存活时 refresh+logs/check；停止的会话保持停止。原生和手机未取得证据时写未验证，离线画面不能代替真机。
