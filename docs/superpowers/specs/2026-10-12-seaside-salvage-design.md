# 正式海边场景与自动捕捞演出

用户在 2026-10-12 确认 1920×1080 海边构图稿，并选择点击开始捕捞后自动下网收瓶。沿用图中的左下木码头、暖金夕照、蓝色海水、右方灯塔和中远景小帆船。网兜入口的既有 0.45 秒推进保持，海边改为分层场景。

## 范围与接口

- 独立底图去除船、瓶子和伸入的网兜；商船复用主页原素材，漂流瓶与网兜制作透明图片，原生成图与远端映射保留。
- UI 使用现有 urhox-libs/UI 的 Render(vg) 与 ImageCache，不创建新的 NanoVG frame。1920×1080 图层等比 contain，继承入口安全区；热区与图层使用同一坐标变换。
- 进入海边和打开商店不收信。捕捞按钮点击时重新查询 GetSalvageView，成功保存的 model.Receive(id) 才启动约 2.4 秒演出。没有可收信件时无漂流瓶；已用尽次数或业务锁定显示真实原因。
- 演出期间屏蔽场景、HUD 和业务按钮，仅允许跳过演出。动画不执行任何存档、跨天、购买或再次收信命令。
- 收瓶完成打开同一真实 Reader。读信保存失败保留“阅读捞到的信”入口；已收信即使关窗也在抽屉，不重播业务。
- 焦点丢失、最小化、改变窗口或长时间帧间隔停止演出并保留已收信入口；销毁不做延迟导航。返回主页可以中止显示，既有进度不回退。
- 保持 PlayModel/main/core/systems/data、主页构图及其他页面业务不变。商店关闭回海边。音效作为后续可选，不阻塞本次图片与交互交付。

## 验收

隔离真实业务测试覆盖：进入不消费、只收一次、成功后延迟读信、保存失败无收获、空海无瓶、每日次数、模态阻挡、跳过、中断、失败读信可重试、返回与重开保留。既有主页与门洞推进回归继续通过。实际窗口仅在已存活的预览中刷新；停止会话不启动。离线帧明确标记，不替代原生或手机验收。
