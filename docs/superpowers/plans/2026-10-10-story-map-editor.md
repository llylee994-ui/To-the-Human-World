# 剧情思维导图编辑器 Implementation Plan

按用户“搭一个具体框架，我随时提出修改，你也能操作编辑器”的授权直接实施本地工具，不提交远端构建。

**Goal:** 用户与 Codex 编辑同一份主线思维导图，保存节点、连线及梗概，明确普通愿望日和主线日交替。

**Architecture:** Python 标准库本机 HTTP 服务；项目 JSON 是唯一正式数据，原子保存、版本冲突拒绝覆盖并备份；无依赖 HTML/CSS/JS 使用 DOM 节点与 SVG 曲线显示思维导图。

**Tech Stack:** Python 3.12、原生 JavaScript、SVG；浏览器测试使用已有运行时 Playwright。

## 约束

- 不改游戏运行数据、既有排版编辑器或正式身份规则。
- 今天普通、明天主线：首日普通，主线放偶数日。初稿16个主线日，形成32天讨论排期；旧18天需后续另行调整。
- 新故事节点为讨论草案；默认不将新增订单纳入学徒考核。
- 同时编辑不允许最后写入者静默覆盖；保存冲突保留本地未保存版本，支持下载，再载入新版本。

## 文件与任务

1. `scripts/story-editor/store.py`：`Store(path).read()/save(project, revision)`；校验唯一ID、父子无环、边端点、主线日偶数/普通日奇数；SHA256版本检查；备份旧数据、原子替换。`tests/test_store.py` 先验证持久化、并发冲突、非法图及损坏输入不覆盖。
2. `scripts/story-editor/server.py`：仅监听127.0.0.1，默认18766；`GET /api/project` 读共享图与令牌，`POST /api/project` 条件保存；显式静态路由，限制来源和输入大小；单进程锁、重启复用，不任意读写路径。
3. `scripts/story-editor/web/`：思维导图、日程导航、右侧节点编辑；添加/复制/删除节点、父级移动、结果连接至已有汇合点、删边；撤销/重做、缩放/拖动、折叠/展开、搜索、导入/导出JSON。修改自动串行保存，远端变更自动刷新或冲突保护。
4. `docs/文案/主线/主线故事图_v01.json`：从讨论稿生成8个前期主线节点、8组成对节点、每候选三类详细结果、跟进梗概、案件和身份结局、32天交替占位。结果分支写进入条件/人物行动/保留后果/下一步；条件为叙事说明，不冒充可执行数值。
5. `启动剧情编辑器.cmd` 与 README：启动、编辑、共享保存、冲突恢复、Codex通过文件/API持续编辑说明。
