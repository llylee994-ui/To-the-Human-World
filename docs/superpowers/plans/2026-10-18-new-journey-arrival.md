# 新旅程入场过渡实施计划

目标：按用户确认的“标题界面淡黑 → 室内渐显，但保持昏暗 → 桌上便签亮起 → 出现旁白”接入。

结构：ArrivalSequence 只处理纯时间轴，ArrivalTransition 持有黑场输入层与一次性的切场回调；AppView 在标题新旅程入口调用，Onboarding 读取便签和旁白透明度。沿用现有 UI、字体、室内背景与存档命令。

- [x] 先补时间轴及真实标题入口回归：黑场切换一次、连点防重、后续存档不重播、失焦暂停、等待布局、不会自动阅读便签或修改背包。
- [x] 实现独立时间轴和 UI 层：淡黑 0.4s、室内渐显 0.7s、便签亮起 0.3s、旁白淡入 0.35s；房间未稳定时保持黑场；使用缓入缓出曲线。
- [x] 接入 AppView 进入/退出/销毁；只在标题进入未读开场便签时播放，不改变继续游戏后续步骤。
- [x] 接入便签光区和底部旁白；展开便签无标题、只有正文与木板收起按钮。
- [x] 跑引导、标题/结局相关回归和 LSP；按 live status → refresh → logs/check 更新本地预览。独立审查后更新已授权的手机测试版。

不新增资源、语音或剧情，不改炼药五步仅提示的规则，不控制电脑或浏览器。
