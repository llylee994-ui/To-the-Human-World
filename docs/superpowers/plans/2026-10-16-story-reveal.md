# 魔法烟雾与后续故事页 Implementation Plan

> 单人执行，遵循 executing-plans；用户明确不使用子代理。

**Goal:** 按用户参考改造全屏魔法揭晓、后续纸页、星级印章和熬制按钮。

**Architecture:** 演出和美术留在 landscape UI；存档、评级、正文、确认发货命令沿用现有业务。烟雾先覆盖屏幕，结果挂载后再淡出。

**Tech Stack:** Lua 5.4 / urhox-libs UI / 自定义 Render / 透明 PNG。

## Constraints
- 不修改剧情、评分、库存、存档或订单业务。
- 评级使用已存储 0–3 星；不使用参考图中的花朵评级。
- 不再在后续正文显示会到期消失的成功通知；持久错误仍可见。
- 本地预览活跃才刷新；不提交、不远端构建。

## Tasks
- [ ] 先增加回归：快速完全遮盖、结果页成功通知隐藏/失败可见、固定星级及动作。
- [ ] 新增 BrewSmoke.lua（覆盖率与绘制）、StoryStyle.lua（按钮皮肤与星章）；接入 BrewView.lua 全局遮罩及揭晓淡出。
- [ ] 重排 ResultView.lua：居中窄纸、标题和寄信人、星章、药效回响、独立正文滚动、固定双按钮；修正 AppView 通知策略。
- [ ] 运行 brew 回归、相关布局回归、LSP、diff 检查；检查保护目录。
- [ ] 活跃本地预览刷新，内存 fixture 原生验收并读取截图；恢复正常模式并记录证据。
