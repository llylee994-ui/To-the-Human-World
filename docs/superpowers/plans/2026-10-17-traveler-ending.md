# 旅人结局展示实施计划

用户已确认船上回望画面、减少灯火、底部渐隐黑底暖白字、点击翻页、结尾渐暗与黄铜细线返回按钮。本计划只实现旅人结局，保留正在其他窗口修改的炼药、词条、学徒和愿望界面。

**Goal:** 购票保存成功后播放五屏旁白，末屏点击后渐暗呈现“旅人／人间单程船票”，显式返回首页。

**Architecture:** `EndingView` 按 departure 路线委托新 `DepartureView`；`DepartureSequence` 维护纯展示时序，页面从已冻结的 ending.text 按空行分段。原购票、扣款、留念与存档事务保持。UI 控件绘制文字，静态背景不含文字；导航与演出不保存。

**Tech Stack:** UrhoX Lua 5.4、urhox-libs/UI、已有隔离业务测试与 Maker 本地预览 CLI。

## 文件边界

- 新建 `scripts/ui/landscape/DepartureSequence.lua`：分段、淡入、翻页、渐暗、落款时序。
- 新建 `scripts/ui/landscape/DepartureView.lua`：背景、底部旁白、点击捕获、落款和返回按钮。
- 修改 `scripts/ui/landscape/EndingView.lua`：仅 departure 分派；学徒和愿望保留原路径。
- 修改 `scripts/data/release_endings.lua` 与三结局正文：保留前四屏已确认文字，末屏使用用户原文，正文以五段保存。
- 新增 `assets/image/departure-ending-r1/background.png`：已确认的单张无字背景与独立 meta。
- 新增 `scripts/ui/landscape/tests/DepartureViewTest.lua` 与启动器；调整现有结局 UI 检查以完成真实翻页再返回。

## 五屏正文

1. 商人收好金币，把船票交给你。船就在码头边，他说现在上船，还来得及找个靠窗的位置。
2. 你回屋熄了灯，把钥匙放在桌上。来信收进抽屉，装药的瓶子排在柜台里。
3. 关门时，你有些舍不得，还是拿着票去了码头。
4. 船离岸后，魔药铺的灯光渐渐远了。你想去看看人间的日出日落，再慢慢走过春夏秋冬。
5. 至于下船后先去哪里，你还没有想好，商人给你指了路，又往你手里塞了一块面包。你道了谢，坐下来慢慢吃，打算下船后先去他说的地方看看。
