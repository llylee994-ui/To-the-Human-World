# 云端完整 3D 候选版：验收范围与运行说明

## 当前结论

完整场景可以在官方 Linux 运行器中真实加载并截图。此版本是继续优化的候选版；用户尚未确认达到 Blender 参考效果。原生界面业务测试通过不能代替美术验收，也不能代替 Windows/手机实机性能测试。

## 已实施的主要修复

- 纹理先声明 sRGB 再上传 GPU，修复灰牌 187→128 所证明的重复伽马泛灰问题；没有给整张图加滤镜冒充游戏效果。
- 精确修复 271 个原模型闭合壳朝向，保留 UV 与位置；另修复新增花瓣朝向。
- 删除桌面日期瓶、金币瓶及其内容物；保留界面日期与金币。
- 中层架子加入海盐、夜露、灰烬草、干花瓣，按 B 布局改善辨识；原料不增加新的 Home 业务入口。
- 恢复原灯笼结构、火焰自发光和暖光。低环境光、桌面局部补光保留暖白桌布与较深木墙。架子补光只采用较克制的强度 2，强度 6 试验未采用。

## 运行与截图

需另外准备已核验的官方 Linux Runtime 整套目录（包含 Autoload 与共享库），不能只复制 ELF 文件。工作包不重新分发运行器。将 URHOX_RUNTIME 指向其可执行文件，D3_CLOUD_OUTPUT 指向一个全新的可写证据目录。

- python tools/run_cloud_capture.py：通过 scripts/main.lua 真实入口加载完整场景，1170×658 同机位截图，记录进程内存及真实墙钟帧时间；等完整 READY 后再读取画面。
- python tools/run_cloud_interaction_check.py：在官方图形引擎中用合成鼠标移动/按下/释放测试 UI。所有业务状态使用隔离 MemoryStorage；不是操作用户电脑鼠标，不写真实玩家存档。
- tools/run_cloud_game.sh：运行持续的云端完整场景。软件离屏渲染不提供桌面交互窗口，若要本机鼠标试玩需在目标设备启动其对应 Runtime。

运行依赖 GLES 软件渲染与官方 -recompile_shader；当前 Linux build 的 3D LUT 路径不兼容，因此固定曝光并采用 TONEMAP_MODE_NONE。没有修改引擎二进制或绕过认证。

## 尚未通过的项目

- 灯与物体之间的局部接触/遮挡阴影仍不足。当前 cluster GLES 路径启用局部阴影会触发 shader 兼容错误；不能用不断加亮或一个 SSAO 开关假装解决。
- 夜露玻璃是 alpha 近似，花瓣/夜露在全景中的辨识仍有改进余地。
- 与 Blender 的反弹光、透明折射、色调映射不能视为完全相同。
- 目标 Windows 与手机帧率、内存、操作体验没有重新验证。云端 Mesa 软件帧率不代表设备性能。
- GitHub 写入返回 403；所有提交目前仅在本地，交付包保留恢复途径，不能称已经推送。

## 最新证据

161 项主接口离线回归与 164 项运行资源哈希检查通过。5996b62 场景的完整原生 UI 回归通过：8 个入口、12 张截图、提示、日期、金币、原捕捞与阅读流程、返回主页，以及隔离内存保存。详见 cloud-native-interactions.json 与 cloud-runtime-resource-integrity.json。正式入口截图和解压包复现单独记录；启动中、日志 READY、离线校验均不独立等于该项成功。

正式 scripts/main.lua 入口截图已真实验证：1170×658、100 模型、3,208,608 三角形、870 绘制对象、8 锚点。READY 后20帧截图成功、进程退出0；画面与所选架子补光2的实验图逐像素一致。总进程87.42秒、VmHWM 2,435,272 KiB，稳态采样14帧中位帧时0.573秒，均仅属Mesa软件环境。详见 cloud-candidate-main-capture.json。独立解压交付包仍需另行复现。
