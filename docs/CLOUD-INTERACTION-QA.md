# 原生界面与业务验收

本轮使用官方 Linux Runtime 的真实图形场景、UI 命中与按下/释放分发，不是 OS 鼠标操作。

- 8 个 Home 入口通过原生相机射线、物体代理命中、UI 输入转页；提示随原对象锚点显示。
- 抽屉、故事记录、分类词条、案件板、商店、信纸、炉子、捞网均到达对应原业务页面。新会话信纸打开来信选择，收到信后能打开原信件阅读页。
- 导航本身无业务状态变化和存档写入；结束当天 1→2，旧确认回调不能再次推进日期。
- 海盐购买金币 30→25；海边真实 Receive 得到 letter_n01，打开阅读页后返回 Home，HUD 第2天/25金币。
- 8次业务保存仅落到独立 MemoryStorage 的 d3_lab_v035 允许路径。退出即丢弃测试进度，不写用户默认存档。

## 复现

设置 URHOX_RUNTIME 为已核验的官方 Linux 运行器，D3_CLOUD_OUTPUT 为独立证据目录，运行 python tools/run_cloud_interaction_check.py。默认保存全部入口截图；D3_QA_CAPTURE_ALL=0 只保留提示、收信、阅读和最终 HUD 截图，入口仍逐项验证。

重要：本版官方注释与实际常量冲突。合成事件使用运行时 MOUSEB_LEFT（本机为1），不硬编码注释中的0。原 Home 按钮过滤未修改。

软件 Mesa EGL/GLES 首屏加载与峰值内存见 cloud-native-interactions.json。不是手机/目标电脑性能结论。美术仍需继续改善；业务通过不表示视觉还原通过。
