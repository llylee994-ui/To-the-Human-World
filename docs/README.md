## 先读什么

负责写剧情时，先读[文案交付索引](文案/README.md)，再读[主线节点表 v0.1](文案/主线/寄往人间_主线节点表_v01.md)和两个普通订单包。涉及玩法判断，以[游戏大纲](设计/寄往人间_游戏大纲草稿_更新版.md)、[身份规则](设计/寄往人间_五类玩家身份与结局判定规则.md)及[内容填写说明](../scripts/data/填写说明.md)为准。

```text
docs/
├─ README.md                         文档导航
├─ 寄往人间_开发计划与验收标准.md        开发固定入口
├─ 寄往人间_系统模块拆分与依赖设计.md    技术固定入口
├─ 设计/                             游戏大纲、案件设定、身份规则、界面设计
├─ 协作/                             队友上手指南
├─ 验证/                             纸面验证
├─ 记录/                             开发者日志
└─ 文案/
   ├─ README.md                      草稿状态、交付边界与编号
   ├─ 主线/                          节点表；后续逐节点正文
   └─ 普通订单/                      人物、来信、可剪词、后果、回信、评分
```

开发计划和系统模块文档留在根目录，保持程序注释与既有交接入口有效。其余七份文档按内容归档；已有 Markdown 引用同步更新。`scripts/` 内的实施记录继续留在原位置，避免把程序交付历史与文案草稿混在一起。
